# 실험 23 — 고정 시드 점수 평균

## 실행 전 고정 계획

22번 MLP의 일부 시드만 수익 개선을 보였다. 좋은 시드를 선택하지 않고, 모든 시드를
같은 비중으로 결합하면 초기화 민감도를 줄일 수 있는지 검사한다. 수익 개선은 미확인이다.

- 첫 단계는 학습을 추가하지 않고 실험 22의 대조·후보 MLP 시드 17/29/43의 동결 예측을 사용한다.
  두 가중 조건 각각 세 점수의 단순 산술평균 > 0.50이면 원래 돌파 진입을 허용한다.
  특정 시드 제외·성과 기반 비중·임계값 탐색·CNN과 혼합은 하지 않는다.
- 동일 분기의 학습/검증 감사 기록, feature_set, 예측 시간 범위, 입력 소스와 사건 해시 일치가
  필수다. 누락 예측을 0으로 대체하거나 존재하는 시드만으로 평균을 계산하지 않는다.
- 매 시점 평균 점수를 만든 뒤 같은 연속 계좌 백테스트를 새로 수행한다.
  개별 모델 수익률이나 포트폴리오를 평균하지 않는다. 전액 매매·원래 청산·위험 중단 유지.
- 두 조건과 원래 돌파·현금·각 가중 조건의 상수 대조를 같은 22개 구간·4비용/지연에서 비교한다.
  분기 경계에서는 새 분기 모델만 예측을 소유하며 결측 경계를 계좌로 연결하지 않는다.
- 첫 단계에도 기존의 대응 수익 차이 중앙값 양수, 양수 구간 과반, 최악 낙폭 10% 이하,
  위험 중단 없음, 기본 비용 자연 청산 10회 이상 기준을 모두 적용한다.
- 첫 단계에서 실패하면 해당 결합 조건은 채택하지 않는다. 통과해도 기존 개별 시드의 실패를
  덮어쓰거나 안정성을 확보했다고 주장하지 않는다.
- 통과한 조건에만 후속 안정성 검증을 수행한다. 사전에 고정한 추가 그룹 (53,67,79),
  (97,109,127)을 각각 같은 조건으로 학습·평균하며, 세 그룹 전체가 모든 비용 기준을 통과해야 한다.
  그룹들은 초기화 민감도 검사이지 독립 시장 표본이 아니다. 좋은 그룹만 선택하지 않는다.
- 현재 자료는 반복 탐색한 자료다. 새 홀드아웃이나 실거래 수익을 입증하지 않는다.
- 실거래·Config Server·DB·계좌·배포·커밋·푸시 변경 없음.

## 재현 명령

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_ensemble \
  --raw data/regime-08-2020-2026-public \
  --control outputs/breakout-overlap-22-control \
  --candidate outputs/breakout-overlap-22-candidate \
  --output outputs/breakout-ensemble-23
```

첫 단계 출력의 `seed-17`은 기존 분석 형식을 재사용하는 저장 슬롯이다.
실제 구성원은 프로토콜의 `[17,29,43]`이며 단일 시드 17의 결과가 아니다.
`additional_groups_required`가 비어 있으면 첫 단계 탈락으로 추가 그룹을 학습하지 않는다.
비어 있지 않아도 안정성 검증은 미완료이며, 별도 후속 학습·검증 없이는 통과를 주장하지 않는다.
