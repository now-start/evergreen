# 실험 21 — 돌파·청산 맥락 입력 결과

## 결론

같은 모델 크기에서 입력만 바꿔도 원래 돌파 대비 일관된 개선을 확인하지 못했다.
MLP/CNN 모두 사전 기준 미달이다. 실거래·Config Server·DB·배포는 변경하지 않았다.
이미 반복 관찰한 역사 자료의 탐색 결과이며 신규 홀드아웃 검증이 아니다.

## 비교 조건과 결과

동일한 32×5 입력, 손익 가중 BCE, 6분기 학습·2분기 검증, 시드 17/29/43,
최대 100 epoch·patience 10·최적 검증 복원. 점수 > 0.50이며 승률로 해석하지 않는다.
편도 수수료 0.05%·슬리피지 0.1%, 전액 매매와 10% 위험 중단을 유지했다.

아래는 22개 연속 구간별 순수익률 중앙값이다. 각 구간은 별도 원금 100만 원으로 시작하며
하나의 계좌 누적 수익률이나 연환산 수익률이 아니다. 미거래 구간도 포함한다.

| 입력 / 모델 | 시드 17 | 시드 29 | 시드 43 |
|---|---:|---:|---:|
| 원래 돌파 | +2.00% | +2.00% | +2.00% |
| 단기 / MLP | +2.00% | +2.35% | +2.00% |
| 맥락 / MLP | +2.00% | +2.00% | +2.00% |
| 단기 / CNN | +2.00% | 0.00% | 0.00% |
| 맥락 / CNN | +2.00% | 0.00% | +2.00% |

맥락 입력과 단기 입력의 대응 구간 수익률 차이 중앙값은 6개 모델/시드 조합에서 모두 0%p다.
맥락 MLP의 자연 청산은 66/66/68회, CNN은 68/42/64회, 원래 돌파는 69회였다.
시드·4개 비용/지연 조건 전체 최악 낙폭은 맥락 MLP/CNN 모두 10.95%였다.
단기 대조는 MLP 10.98%, CNN 10.95%. 위험 중단은 체결 지연·비용을 포함한 손실 상한이 아니다.

## 거래 손익 대사

원래 돌파 대비 원화 손익 차이 합계다. 독립 계좌 22개에 각 100만 원, 총 배정 원금 2,200만 원.
신호가 같은 거래의 차이, 제외된 거래, 추가된 거래를 합쳐 최종 자산 차이와 대사했다.

| 입력 / 모델 | 시드 17 | 시드 29 | 시드 43 |
|---|---:|---:|---:|
| 단기 / MLP | -142,314원 | +364,908원 | -207,499원 |
| 맥락 / MLP | -237,794원 | -258,505원 | -145,460원 |
| 단기 / CNN | -160,142원 | -473,418원 | -153,303원 |
| 맥락 / CNN | -188,791원 | -364,285원 | +46,487원 |

맥락 입력이 나은 경우도 있지만 전체 시드에서 개선되지 않는다. 특히 MLP 시드 29는 악화됐다.
평가 구간의 완결 가상 사건 458개(양수 218·0 이하 240)에서 맥락 MLP가 놓친 양수 사건은
18/23/8개, 회피한 0 이하 사건은 20/26/19개였다. CNN은 각각 12/72/30개와 6/87/44개다.
겹치는 가상 사건과 실제 전액 매매는 다르므로 이 개수만으로 계좌 수익 개선을 주장하지 않는다.

## 검증과 한계

- 두 조건 각각 114개 모델 학습·저장·재로딩. 2,640개 백테스트에는 반복 대조군이 포함된다.
- 사건 파일·자료 coverage 파일이 바이트 단위로 같고, 57개 분기/시드의 전체 감사 기록
  (학습/검증 표본 해시·가중치·사전 기준 포함)이 두 조건에서 정확히 같았다.
- 모든 시드·연속 구간·비용 조건에서 원래 돌파·현금·상수 대조군 결과가 정확히 같았다.
- 200시간 준비 구간으로 평가 범위는 36,384시간, 계획 40,896시간의 88.97%, 22개 구간이다.
  19/20번보다 682시간 줄었다. 따라서 169시간 준비 결과와 직접 수치만 비교하지 않았다.
  결측 보간이나 결측 경계를 넘는 계좌 연결은 없다.
- 전체 사건은 완결 701개(양수 335·0 이하 366), 중도 관측 종료 58개.
  순차적으로 겹치지 않게 고른 사건은 110개뿐이다. 701개를 독립 표본으로 간주하지 않는다.
- 미래 봉을 추가해도 과거 입력은 같고, 현재 고가·저가는 이전 상단/하단에 들어가지 않는다.
  단기 입력은 기존 입력의 정확한 시각 절단이며, 같은 사건의 레이블·시각도 일치한다.
- 모델 메타데이터가 입력 종류를 보존하고 재로딩 예측이 같다. 기존 기본 신경망의 고정 표본
  체크포인트는 변경 전과 바이트 단위로 같았다.
- 전체 테스트 333개 통과·테스트용 MariaDB 미설정 22개 제외, 커버리지 89.75%.
  이후 추가한 실험 21 오류 분석 분기 포함 해당 테스트 13개도 통과했다.
  Ruff 검사·포맷, mypy, diff 공백 검사를 통과했다.
- 사용자 승인 대체 모델 gpt-5.5의 읽기 전용 독립 CLI 리뷰: APPROVE, 조치가 필요한 발견 없음.
- 단기 CNN 57개 중 6개는 최대 100 epoch에 도달했다. 나머지 세 입력/모델 조합은 모두
  조기 종료했지만, 이것이 수렴이나 수익성을 증명하지는 않는다.
