# 실험 05 — 규칙과 딥러닝 혼합 사전 계획

## 범위와 고정 후보

실험 04의 조기 종료 MLP·CNN 가중치를 그대로 사용한다. 재학습·확률 임계값 탐색은 하지 않는다.
각 모델에 아래 세 규칙을 붙인 **6개 후보**만 비교한다. 분할 매매 없이 현금 또는 전액 BTC이며,
확정 시간봉의 신호를 다음 시가에 체결한다. 기존 비용·지연·10% 낙폭 중단 로직을 그대로 사용한다.

1. **추세 필터**: 기존 SMA 48/168 진입 조건과 확률 ≥ 0.60이 동시에 만족해야 매수.
2. **돌파 확인**: 기존 168시간 고점 돌파 진입과 확률 ≥ 0.60이 동시에 만족해야 매수.
3. **RSI 반등 확인**: 기존 추세 필터 RSI 반등 진입과 확률 ≥ 0.60이 동시에 만족해야 매수.

모든 혼합 후보는 보유 중 원래 규칙의 매도 조건 **또는** 확률 ≤ 0.45이면 매도한다.
진입은 AND, 청산은 OR이다. 딥러닝이 기존 위험 청산을 막을 수 없다.

## 선택·평가 절차

- 선택: 기존 2025년 세 구간을 사용한다. 이미 관찰한 자료이므로 탐색용이다.
- 선택 후보는 혼합 6개로 한정한다. 3개 구간 × 4개 비용/지연 조건의 최저 순수익률을 최대화한다.
- 다만 모든 선택 조건에서 낙폭 ≤ 10%, 위험 중단 없음, 기본 조건의 합계 청산 ≥ 3회인 후보만 적격이다.
  동률은 낮은 최악 낙폭, 전략 ID 순. 적격 후보가 없으면 현금 유지로 돌아간다.
- 수익이 없더라도 결과를 숨기거나 기준을 완화하지 않는다. 적격·순위 1위는 실거래 승격이 아니다.
- 혼합 후보 선택과 모델 해시를 저장한 **뒤에만** 후속 평가 자료를 읽는다.
- 후속 재비교: 이미 관찰한 2026-01-13 ~ 03-01 UTC.
- 새 후속 평가: 2026-07-09 ~ 09-01 UTC (워밍업 포함 수집 07-01 ~ 09-01).
  이 구간의 거래 성과는 선택 전에 확인하지 않는다. 결측 시 실패를 기록하고 다른 구간으로 바꾸지 않는다.
- 후속 평가는 선택한 혼합 후보 하나와 기존 일곱 규칙/기준, 독립 MLP·CNN만 수행한다.

원금은 구간별 100만 원, 편도 수수료 0.05%·슬리피지 0.1%.
기본·슬리피지 2배·전체 비용 2배·한 시간 지연의 네 조건을 유지한다.
순수익률·최악 낙폭·거래 수·단독 모델/규칙 대비 차이를 한글로 보고한다.
새 평가가 있어도 과거의 반복 탐색 편향이 사라지지 않으며, 장기 수익성 입증으로 취급하지 않는다.

현재는 계좌·주문·자동 승격을 연결하지 않는다. 모델/실험 입력과 소스 해시를 보존하고 기존 결과를 덮어쓰지 않는다.

## 실제 결과

6개 혼합 후보와 9개 단독·기준 전략을 선택 3구간에서 비교하고, 기존 2026년 구간까지
총 **216개 백테스트**를 완료했다. 모델 재학습 없이 실험 04의 MLP 최적 3 epoch,
CNN 최적 24 epoch 가중치를 복사·해시 검증해 사용했다.

| 혼합 후보 | 2025년 1~2월 기본 수익률 | 4~5월 | 7~8월 | 기본 청산 합계 |
|---|---:|---:|---:|---:|
| MLP + SMA 추세 | -0.57% | 0.00% | 0.00% | 2 |
| CNN + SMA 추세 | +1.03% | 0.00% | 0.00% | 1 |
| MLP + 고점 돌파 | 0.00% | 0.00% | 0.00% | 0 |
| CNN + 고점 돌파 | 0.00% | 0.00% | 0.00% | 0 |
| MLP + RSI 반등 | 0.00% | 0.00% | 0.00% | 0 |
| CNN + RSI 반등 | +0.22% | 0.00% | 0.00% | 1 |

날짜는 위 사전 계획의 기존 2025년 선택 구간과 동일하다. 모든 후보가 청산 합계 3회에
미달해 **현금 유지**가 선택됐다. 0%를 유망한 무손실 전략으로 해석하면 안 된다.
동시 동의 필터가 거래를 지나치게 줄였다는 결과이며, 혼합이 단독 MLP보다 낫다는 근거는 없다.
기준을 완화하거나 2026년 성과로 혼합 후보를 다시 선택하지 않았다.

새 구간 수집은 첫 시도에서 실행 환경 DNS 제한으로 실패했다. 네트워크 접근을 허용한 재수집에서는
공개 API 응답을 받았지만, 2026-07-05 18:00/19:00/20:00 UTC 시간봉 세 개가 없었다.
이는 워밍업에 포함되는 공백이므로 기존 연속성 정책에 따라 새 평가를 중단했다.
누락은 0% 수익이 아니며, 원인이 무체결·점검·API 문제 중 무엇인지는 이 자료만으로 확정하지 않는다.

로컬 `outputs/hybrid-experiment-05-final/summary.md`에 상세 비교를, `failure.json`에 미완료를,
`data/experiment-05-test-new-retry/quality.json`에 누락 시각과 원본 응답 해시를 보존했다.
성공 `status.json`은 없고 실거래·승격도 하지 않았다.
원실행과 검증 재실행의 216개 결과는 동일했다. 독립 리뷰에서 지적한 손상 메타데이터의
실패 보고 누락도 보완했다. 최종 코드 재실행 결과는 `-final` 경로에 별도로 보존한다.

다음 설계 후보는 규칙의 진입 시점에 맞춘 별도 수익성 레이블(메타 라벨링)이다.
현재의 일반 12시간 상승 확률을 규칙의 거래 성공 확률로 해석하지 않는다. 이는 후속 제안이며 미구현이다.
