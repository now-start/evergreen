# 실험 22 — 겹침 가중치 결과

## 결론

겹치는 사건의 학습 기여를 줄이면 MLP 일부 시드의 계좌 손익은 개선되지만, 모든 시드와
비용·위험 조건에서 우위를 확보하지 못했다. MLP/CNN 모두 기존 사전 기준 미달이다.
실거래·Config Server·DB·배포는 변경하지 않았다. 과거에 반복 관찰한 자료의 탐색 결과다.

## 기본 비용 비교

단기 32×5 입력·200시간 준비, 6분기 학습·2분기 검증, 원래 돌파 청산 레이블,
최대 100 epoch·patience 10, 점수 > 0.50. 후보는 절대 순수익 가중치에 분할 내
평균 역수 겹침 계수만 곱했다. 해당 점수를 승률로 해석하지 않는다.

22개 연속 구간마다 원금 100만 원을 독립 배정한 순수익률 중앙값이다.
편도 수수료 0.05%·슬리피지 0.1%, 미거래 구간 포함. 단일 계좌 누적·연환산 수익이 아니다.

| 모델 / 가중치 | 시드 17 | 시드 29 | 시드 43 |
|---|---:|---:|---:|
| 원래 돌파 | +2.00% | +2.00% | +2.00% |
| MLP / 순수익만 | +2.00% | +2.35% | +2.00% |
| MLP / 겹침 조정 | +2.00% | +2.35% | +1.76% |
| CNN / 순수익만 | +2.00% | 0.00% | 0.00% |
| CNN / 겹침 조정 | -0.02% | 0.00% | 0.00% |

후보의 자연 청산은 MLP 64/64/62회, CNN 58/17/38회다. 기본 비용의 위험 중단 구간은
MLP 3/1/3개, CNN 3/0/3개였다. 시드·4개 비용/지연 조건 전체 최악 낙폭은 두 모델 모두
10.95%다. 위험 중단 10%는 다음 봉 체결·비용을 고려한 실제 손실 상한이 아니다.

## 원래 돌파 대비 계좌 손익 차이

각 100만 원인 22개 독립 모의 계좌, 총 배정 원금 2,200만 원의 차이 합계다.
동일 진입·제외 진입·추가 진입의 체결 손익을 최종 자산 차이와 대사했다.

| 모델 / 가중치 | 시드 17 | 시드 29 | 시드 43 |
|---|---:|---:|---:|
| MLP / 순수익만 | -142,314원 | +364,908원 | -207,499원 |
| MLP / 겹침 조정 | +211,053원 | +305,444원 | -186,093원 |
| CNN / 순수익만 | -160,142원 | -473,418원 | -153,303원 |
| CNN / 겹침 조정 | -621,531원 | -1,206,448원 | -945,172원 |

MLP 시드 17은 좋아졌지만 29는 대조보다 나빠졌고, 43은 여전히 원래 돌파보다 나쁘다.
좋은 두 시드만 골라 채택하지 않는다. CNN의 거래 감소를 위험 관리 개선으로 해석하지 않는다.

## 가중치와 오류

평가 구간의 완결 가상 사건 458개(양수 218·0 이하 240)에서 후보 MLP가 놓친 양수 사건은
61/69/40개, 회피한 0 이하 사건은 55/60/38개였다. CNN은 각각 57/193/128개와 50/200/148개다.
특히 CNN 시드 29는 손실 사건을 많이 피했지만 수익 사건도 대부분 놓쳤다.
가상 사건은 서로 겹치며 실제 전액 매매 체결과 같지 않다.

학습 분기별 최대 동시 사건 수는 11~34개였다. 가중 상수 점수의 범위는 대조 0.406~0.817에서
후보 0.294~0.599로 낮아졌다. 상위 5개 가중치 비중은 9.60~23.69%에서 11.99~23.79%로,
겹침을 조정했다고 모든 의미의 가중치 집중이 줄어드는 것은 아니다.

## 검증

- 두 실행과 오류 분석 모두 종료 코드 0. 조건별 114개, 총 228개 모델 학습·재로딩 검증.
  총 2,640개 백테스트에는 반복 대조군이 포함된다.
- 대조 모델 114개 체크포인트는 실험 21 대조와 바이트 단위로 같고 모든 백테스트 결과도 같다.
- 두 조건의 사건·coverage 파일이 같고 57개 분기/시드의 학습/검증 표본 시각·레이블 해시가 같다.
  원래 돌파·현금 결과도 모든 구간·비용에서 일치한다. 상수는 변경된 가중치를 반영하므로 다를 수 있다.
- 평가 범위 36,384시간, 계획 40,896시간의 88.97%, 22개 연속 구간으로 실험 21과 같다.
  완결 701개·중도 관측 종료 58개, 비중첩 순차 선택 110개. 새로운 독립 표본이 생긴 것이 아니다.
- 학습/검증 분할별로만 겹침 수 계산. 경계 맞닿음·부분 중첩·순열·분할 밖 사건 제외·잘못된
  구간 거부, 모델 연결 및 오류 분석 분기를 테스트했다.
- 전체 테스트 344개 통과, 테스트용 MariaDB 미설정 22개 제외, 커버리지 89.75%.
  마지막 감사 기록 단언을 포함한 파이프라인 테스트 26개 재실행도 통과했다.
  Ruff 검사·포맷, mypy, diff 공백 검사 통과. 실행 시 소스 해시와 현재 소스도 같다.
- MLP는 대조·후보 모두 100 epoch 전에 조기 종료했다. CNN은 대조 6개, 후보 3개가 상한에
  도달했다. 조기 종료를 수렴·수익성 증거로 간주하지 않는다.
- Spark 사용량 제한 후 사용자가 대체 모델 사용을 명시적으로 허용했다.
  gpt-5.5 읽기 전용 독립 CLI 리뷰 결과 APPROVE, 조치가 필요한 발견 없음.

## 다음 가설

MLP의 시드별 계좌 결과가 엇갈리므로, 좋은 시드를 선택하는 대신 사전에 정한 모든 시드의
점수를 같은 비중으로 합치는 실험을 검토한다. [실험 23 계획](breakout-meta-experiment-23.md)은
합산 결과를 보기 전에 고정하며, 평균화가 위험 기준을 해결한다고 전제하지 않는다.
