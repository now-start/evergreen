# 실험 29 — 청산 채널과 계좌 위험 여유

## 실행 전 고정 계획

실험 28의 개선 대부분은 한 계좌의 초기 손실을 피하면서 이후 영구 위험 중단을
피한 효과였다. 이번에는 진입 시점의 계좌 상태와 기존 청산 채널을 함께 본다.
실험 28 후속 사후 진단에서 예상 채널 청산 후 잔액이 당시 고점의 90% 이상인
기존 거래는 54건 중 23건 수익(+513,554원), 미만은 18건 중 10건 수익(+675,965원)이었다.
즉 위험을 줄이려다 큰 수익을 놓칠 가능성이 있고, 실제 경로를 재계산해야 한다.

- 후보 하나 `channel-budget`: 원래 돌파가 매수를 제안할 때만 아래 계산을 한다.
  현재 확정 종가로 전액 매수하고, 이전 48개 봉 최저가로 전액 매도한다고 가정한
  잔액이 현재까지 계좌 고점 ×0.90 이상이면 진입을 허용한다. 같으면 허용한다.
- 매수 단가 = 현재 확정 종가 ×(1+매수 슬리피지).
  수량 = 현금 / (1+매수 수수료) / 매수 단가를 기존 수량 단위로 내림.
  잔액 = 현금 − 수량×매수 단가×(1+매수 수수료)
  + 수량×이전48봉 최저가×(1−매도 슬리피지)×(1−매도 수수료).
  봉 최저가 계산에서 현재 봉은 제외한다. 수량·최소 주문 판정은 기존 엔진을 유지한다.
- 계산에는 해당 시나리오 비용을 사용하므로 비용 스트레스에서 진입 판단이 달라질 수 있다.
  고점·현금은 후보 자신의 현재까지 계좌 경로를 사용한다. 대조 계좌나 미래 곡선을 사용하지 않는다.
- 실제 체결은 기존대로 다음 시가, 지연 시나리오에서는 추가 1시간 뒤 시가다.
  신호 이후 시가를 미리 확인하거나 과거 신호를 취소하지 않는다.
  채널 변동·가격 갭·고점 갱신·지연으로 실제 낙폭은 10%를 넘을 수 있으며 손실 보장이 아니다.
- 원래 168시간 고점 ×1.001 진입, 48시간 저점 청산, 10% 영구 위험 중단 유지.
  이전 필터·빠른 청산·재진입 대기와 결합하지 않는다. 손실 한도를 늘리거나 중단을 해제하지 않는다.
- 실험 28과 원자료 SHA·22연속 계좌·200시간 워밍업·36,384시간을 고정한다.
  평가 계획 40,896시간 대비 88.97%, 결측 보간 없음, 분기에서 계좌 유지.
  각 계좌 원금은 독립 100만 원이며 단일 누적 계좌가 아니다.
- 기본/슬리피지2배/왕복비용2배/추가1시간지연으로 원래 돌파·현금·중복 대조 `prior`와 비교.
  원래 돌파 88개 전체 결과가 실험 28과 같아야 한다.
- 네 조건 모두 대응 수익 차이 중앙값 >0, 수익 구간 과반, 최악 낙폭 ≤10%, 중단 없음,
  기본 자연 청산 ≥10회를 요구한다. 위험 감소만으로 수익성 실패를 덮어쓰지 않는다.
- 이미 본 자료의 탐색이며 새 홀드아웃이 아니다. 학습 모델 없음, `seed-17`은 저장 슬롯.
