# 실험 31 — 두 시간 연속 돌파 실패 청산

## 사전 계획

실험 30의 1시간 실패 청산은 기본 조건의 거래를72→117건으로 늘렸고,
22개 독립 구간 합산 손익을 기존보다127,267원 감소시켰다. 일시 이탈 후 회복을
너무 일찍 잘라내는 사례가 관찰되어, 미리 기록한 두 시간 확인 가설 하나만 시험한다.

- 후보 `failed-breakout-2h`: 실제 매수 신호의 이전168봉 최고가를 고정하며,
  **실제 매수 이후 보유 중 두 개 연속 확정 종가**가 모두 기준보다 낮으면 매도 신호.
  동일 가격 또는 기준 위 종가는 연속성을 끊는다. 매수 전 봉은 포함하지 않는다.
- 실제 새 매수에서 기준을 다시 잡는다. 지연 체결에서도 기준은 원래 신호 시각의
  이전168봉이다. 48봉 저점 청산·10% 영구 위험 중단은 두 시간 확인을 기다리지 않는다.
- 다음 시가 체결, 추가1시간 지연 스트레스, 최소 주문·수량 단위, 전액 매수·매도와
  기존 비용을 유지한다. 10% 중단이 실제 손실 상한을 보장하지는 않는다.
- 1시간 조건은 고정 대조일 뿐 1/2/3시간 그리드나 사후 최적화는 하지 않는다.
  기존 돌파·현금·`prior`·실험30 1시간 청산과 비교한다. 원래 돌파88개와 1시간 청산88개
  전체 JSON의 실험30 재현을 완료 상태의 필수 조건으로 둔다.
- 같은 원자료 SHA·22연속 계좌·200시간 워밍업·36,384/40,896시간(88.97%)을 사용한다.
  결측 보간 없음, 연속 구간 내부 분기 경계는 상태 유지, 각 구간 독립 원금100만 원.
  단일 누적 계좌·연환산 수익률로 표현하지 않는다.
- 기본·슬리피지2배·수수료와 슬리피지2배·추가1시간지연 모두 기존 돌파 대비 대응
  수익률 차이 중앙값>0, 수익 구간 과반, 최대 낙폭≤10%, 중단 없음,
  기본 자연 청산10회 이상을 요구한다. 1시간 대조보다 나아도 기존보다 못하면 미달이다.
- 이미 본 과거 자료의 탐색이다. 딥러닝 학습·새 홀드아웃 검증·실거래 승격이 아니다.
  실거래·Config Server·DB·배포·버전·커밋·푸시는 변경하지 않는다.

### 실패 원인과 다음 가설

- 기본 완결 거래는 1시간 청산117→2시간105건으로 줄었지만 원래72건보다 많다.
  2시간 후보의 수수료108,033원·슬리피지 비용216,068원은 기존75,691원·151,383원보다 높다.
- `block-014`에서는 기존 대비 손익 차이가 실험30의 -173,154원에서 -19,145원으로
  줄었다. 그러나 `block-003`은 원래2거래에서6거래로 증가해 기존보다74,999원 악화했다.
  원래 수익이었던2022-07-18 진입을 당일 -16,606원으로 청산하고, 다음 재진입에서도
  -17,872원을 기록했다. 날짜는 UTC다. 확인 시간을 늘려도 회복 기회를 잘라낸 사례가 남는다.
- `block-011`의 개선 +275,153원을 제외한 나머지21개 구간 합계 차이는 -260,950원이다.
  기본 합계가 소폭 양수인 결과는 특정 구간에 의존한다. 최대 낙폭·중단 조건도 미달이다.
- 사후 가격 경로 진단: 기존48시간 저점 조건은 충족하지 않고 두 시간 돌파 실패만으로
  청산한 기본 거래57건 중32건은, 청산 신호 종가의 돌파선 이탈 폭이 **진입 신호 이전
  24봉 평균 True Range 이하**였다. 이탈 폭/평균 True Range 중앙값은0.819다.
  작은 변동까지 실패로 보는 가능성을 보여주는 진단이지, 이32건을 유지하면 수익이
  좋아진다는 반사실적 백테스트 결과가 아니다.

다음 실험32는 시간 확인을 더 늘리지 않고 가격 변동 폭을 반영한다. 진입 신호 이전
24봉의 `max(고가-저가, |고가-이전종가|, |저가-이전종가|)` 단순 평균을 진입 시 고정하여,
돌파선에서 이 값 하나를 뺀 가격보다 종가가 낮으면 다음 시가에 청산한다.
신호 봉은 평균에서도 제외하며 새 실제 매수마다 다시 계산한다. Wilder 평활화가 아니다.
두 시간 확인은 결합하지 않고 한 개 확정 종가만 사용한다. 0.5/1/2배 그리드나 사후 선택은
하지 않는다. 기존 청산·위험·원자료·비용·지연·평가 기준은 유지한다. 아직 실행하지 않은
단일 사전 가설이며, 반복 관찰한 과거 데이터의 탐색으로 취급한다.
