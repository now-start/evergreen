# 실험 34 — 진입 전 변동 폭으로 보유 고점 추적

## 실행 전 고정 계획

실험33의 남은 위험 중단 구간은 평가 고점에서 이익을 반납한 뒤 다음 거래 손실로
10% 낙폭을 넘었다. 진입 제한을 추가하는 대신 보유 중 가격 고점에서 내려올 때
청산하는 규칙을 검증한다. 해당 구간만 예외 처리하거나 손실 기준을 늘리지 않는다.

- 후보 하나 `trailing-tr24`. 원래 이전168시간 고점 ×1.001 진입을 유지한다.
  실제 매수 이후 최고 확정 종가(최초 매수 기준 시가 포함)에서 **진입 신호 전24봉
  평균 True Range의3배**를 뺀 가격 미만으로 종가가 내려오면 다음 시가 매도한다.
  같은 값이면 추가 청산하지 않는다. 가격 고점에는 봉 고가·체결 전 종가를 넣지 않는다.
- True Range는 `max(고가-저가, |고가-이전종가|, |저가-이전종가|)`의 단순 평균이다.
  신호 봉을 제외하고 이전종가 계산용25번째 과거 봉을 포함한다. 실제 매수 시 원래 신호
  시각 기준으로 고정하며 새 매수마다 다시 계산한다. 매도 후 가격 고점과 변동 폭을 지운다.
- 평균이0이면 이 추가 청산은 꺼진다. 원래48시간 저점 청산·10% 영구 위험 중단은 유지한다.
  위험 청산은 우선하고, 체결 거절·지연·분기 경계·구간 끝 정산은 기존 엔진대로 처리한다.
  전액 매수/매도이며 추가 투입·분할 거래·진입 캡·실험30~32 청산·재진입 대기는 결합하지 않는다.
- 24시간·3배는 고정된 한 후보이고 최적 배수라는 주장이 아니다. 짧은 변동 폭 때문에
  청산·재진입·비용이 늘거나 큰 추세 수익을 놓칠 수 있으므로 전체 경로를 다시 계산한다.
- 대조는 원래 돌파·현금·prior·실험33의 진입 캡. 기존과 캡의176개 전체 결과 JSON이
  실험33과 일치해야 완료 처리한다. 후보는 캡 없이 원래 진입, 캡 대조는 추적 청산 없이
  기존 청산이다. 실험30~32 청산은 회귀 테스트로 보존하며 이번 후보에 연결하지 않는다.
- 같은 원자료SHA·22개 연속 구간·200시간 워밍업·36,384/40,896시간(88.97%).
  각 구간 독립 원금100만 원, 구간 내부 분기 경계는 상태 유지, 결측 보간 없음.
  매수·매도 각각 수수료0.05%, 슬리피지0.1%, 최소 주문5천 원, 수량 단위0.00000001.
- 기본·슬리피지2배·수수료와 슬리피지2배·추가1시간 체결 지연 모두 기존 대비 대응 수익률
  차이 중앙값>0, 수익 구간 과반, 최대 낙폭≤10%, 위험 중단 없음, 기본 자연 청산10회 이상.
  위험 중단은 갭·비용·지연을 포함한 실제 손실 상한 보장이 아니다.
- 이미 반복 관찰한 과거 자료의 탐색이며 새 홀드아웃·딥러닝 학습·실거래 성과가 아니다.
  구간 손익 합계를 단일 계좌 누적 또는 연환산 수익으로 부르지 않는다.
  실거래·Config Server·DB·배포·버전·커밋·푸시 변경 없음.


### 실패 원인

- 기본 완결 거래72→124건. 수수료75,691→126,977원, 모형상 슬리피지151,383→253,955원.
  조기 청산 뒤 재진입으로 비용이 늘고 추세 보유 경로도 달라졌다. 비용 증가만으로
  손익 차이 전체가 설명되는 것은 아니다.
- 가장 큰 악화는 `block-005`의 -324,392원이다. 기존5거래의 +446,850원 대신
  후보12거래는 +122,458원이다. 2023-01-11부터 이어진 추세를 여러 번 끊으면서
  초기 이익이 작아지고 중간 손실 거래가 추가됐다. 날짜는 UTC이며 자본 경로도 다르다.
- 문제를 관찰한 `block-003`에서도 기존2거래 -3,471원 대신 후보6거래 -67,096원이다.
  2022-07-18 진입을 당일 청산한 후 재진입했고, 이후 손실과 거래 비용이 쌓여
  고점 대비10.69% 낙폭에 도달했다. 한 구간의 이익 반납을 줄이려는 의도가 개선 증거는 아니다.
- 원래48시간 저점 청산으로 설명되지 않는 추가 추적 청산은108개다. 그중 매수 이후
  최고 가격 상승 폭이 고정 청산 거리(3×진입 전 평균 TR)에 못 미친55개는 모두 손실,
  합산 -979,432원이다. 거리 이상 상승한53개는42개 수익·합산 +1,755,098원이다.
  이 구분은 청산 기준이 매수가보다 아래/위에 놓이는 구조와 직접 연결되어 있으므로
  **미래 수익을 예측하는 특징을 발견했다는 뜻이 아니다.** 손실55개를 제거하면 그 금액만큼
  좋아진다는 해석도 안 된다. 청산을 늦추면 손실이 더 커질 수 있다.

### 다음 사전 명시 가설 — 이익이 생긴 뒤 추적 청산 활성화

실험35에서는 원래 돌파 진입·48시간 저점 청산·10% 영구 위험 중단을 유지한다.
추적 거리와 계산은 실험34 그대로24시간·3배를 고정하되, 보유 최고 종가(매수 기준 시가
포함)가 매수 기준 시가+고정 추적 거리 **이상**이 된 뒤에만 추가 추적 청산을 활성화한다.
한 번 활성화되면 해당 보유 기간에는 유지하고, 새 매수마다 변동 폭·고점·활성 상태를 초기화한다.
신호 봉·체결 전 가격 제외,0변동 폭이면 추가 청산 비활성, 다음 시가/추가1시간 지연은 동일하다.

변경은 이 활성 조건 하나이며 임계 배수 탐색이나 진입 캡·다른 조기 청산 결합은 하지 않는다.
활성 전에도 원래 채널 청산과 위험 중단은 적용한다. 매수 비용을 차감한 손익 보장선은 아니며,
추가 초기 손절을 없애면 기존의 큰 손실을 다시 겪을 수 있다. 기존·실험34 대조와 같은 비용·
구간·낙폭·수익성 기준으로 재계산해야 한다. 아직 구현·실행하지 않은 가설이고 새 홀드아웃이 아니다.
