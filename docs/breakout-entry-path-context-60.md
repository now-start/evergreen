# 실험60 — 진입 가격 경로로 고정하는 추세 맥락

## 실행 전 계약

59의 사전 계획을 그대로 실행한다. 원래 매수 신호 봉 `s`에서
`advance = close[s] - close[s-24]`,
`travel = sum(abs(close[j]-close[j-1]), j=s-23..s)`를 계산한다.
`2 * advance > travel`이면 168봉 추세 맥락, 아니면 24봉을 선택한다.
동률·횡보·순하락은 짧은 맥락이다. 신호 봉까지 확정된 25개 종가를 사용하고,
이후 체결 지연 중의 봉을 포함하지 않는다. 필요한 과거가 없으면 실행을 거절한다.

선택은 원래 신호 시점의 과거만 사용해 실제 매수 체결 시 확정하고 해당 포지션의
청산까지 고정한다. 매수 거절은 보유 상태를 만들지 않는다. 다음 실제 매수에서는
다시 선택하되 계좌 현금·고점·위험 중단은 초기화하지 않는다. 59의 3 TR 조건과
결합하지 않으며 50%·24시간 창을 검색하지 않는다.

57의 비용 차감 청산 여유, 진입 예산, 예약 유지·거절 재시도·채널 재진입,
고점 대비 10% 영구 중단, 기존 위험 주문 교체 시 추가 지연을 유지한다.
53~55의 연장 분기나 새 청산 규칙을 섞지 않는다. 방향성 있는 가격 경로가
추세 지속을 구분한다는 가설과 일방향 급등 끝의 불리한 보유를 늘릴 수 있다는
반대 가설을 함께 검증한다. 최대 손실 보장을 주장하지 않는다.

대조는 기존/50/51/57/58/59이며, 22개 독립 계좌·각 100만원·36,384시간·200봉
워밍업·기본/슬리피지 2배/비용 2배/체결 1시간 지연을 유지한다. 기존/prior 대비
계좌별 수익률 차이 중앙값 > 0, 양수 계좌 절반 초과, 최대 낙폭 10% 이내,
위험 중단 0개, 기본 경계 정산 외 청산 10개 이상이라는 게이트를 바꾸지 않는다.
선택 분포·전체 계좌 경로·이익 집중·비용과 지연 민감도를 함께 확인한다.

이미 관찰한 탐색 자료이며 새로운 미관측 검증이 아니다. 학습 모델을 추가하지
않고 실거래·설정 서버·DB·배포·버전·커밋은 변경하지 않는다. 리뷰는 요청대로 생략한다.

## 후속 실험61 사전 계획 — 같은 진입 상태의 보유 선택 진단

59/60의 서로 다른 진입 특징 모두 통과하지 못했다. 다음에는 또 다른 임계값을
추가하기 전에, **동일한 진입·동일한 계좌 상태**에서 짧은/긴 보유 선택 자체에
어떤 이익과 위험 차이가 있었는지 분리한다. 새로운 실거래 전략이 아니라 이후
선택 모델의 타깃이 성립하는지 확인하는 오프라인 진단이다.

60에 재현된 57(`liquidation-buffer`)의 실제 매수 신호를 기준으로 삼는다.
각 신호마다 그 매수까지는 57을 그대로 재생하고, 해당 한 포지션만 168봉 맥락으로
바꾸는 반사실 경로를 만든다. 대조는 동일 시점까지 같은 상태에서 24봉을 유지한다.
매수 체결·수량·수수료·현금·BTC·계좌 고점과 그 이전 자산 곡선/체결을 일치시켜
검사한다. 매도 후 맥락은 원래 24봉으로 돌아가되 실제 자금/고점은 보존한다.

라벨은 두 경로의 해당 첫 포지션 순손익 차이와 낙폭·위험 중단·청산 시각이다.
수수료·슬리피지·최소금액·체결 지연·예약·채널·진입 예산을 동일하게 둔다.
둘 중 하나라도 경계 강제 정산으로 끝나면 완결 라벨 대신 검열 사례로 표시한다.
완결된 경우 차이 절댓값 0.000001원 이내는 동률로 분리한다. 입력 특징은 오직
원래 진입 신호까지, 라벨 가용 시각은 두 매도 중 늦은 시각으로 기록한다.

59/60이 선택한 맥락과 반사실 손익 부호를 비교하되 미래 결과로 거래를 선택하지
않는다. 서로 겹치는 반사실 거래의 좋은 손익을 합쳐 달성 가능한 계좌 수익이나
게이트 통과로 주장하지 않는다. 네 비용 조건의 같은 신호도 독립 학습 표본으로
취급하지 않는다. 단일 거래 차이와 후속 계좌 상태의 연쇄 효과를 구분한다.

이 진단에서는 모델 학습·특징/임계값 검색·실거래 승격을 하지 않는다. 완결 표본 수,
짧은/긴 선택의 손익 분포, 위험 사례, 두 규칙의 잘못된 선택 유형을 확인한 뒤
다음 가설을 정한다. 61은 아직 구현·실행하지 않았으며 60은 채택하지 않는다.
전체 수익성 목표는 미달성이다.
