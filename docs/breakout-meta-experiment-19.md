# 실험 19 — 거래 손익 규모를 반영한 학습 목적

## 실행 전 고정 계획

실험 18에서 승패 점수의 안정적 개선이 없었고, 거절된 가상 사건에 큰 수익이 남았다.
이 현상만으로 미래 우위를 주장하지 않는다. 다음은 기존 입력·모델을 유지하고 손실 함수만
비용 차감 거래 손익 규모를 반영하도록 변경하는 탐색이다. 이 문서 작성 시 학습·평가는 미실행이다.

- 데이터: 실험 16/17과 같은 검증된 공개 봉·완결 사건·22개 평가 블록. 결측 보간 없음.
- 분할: 6분기 학습, 2분기 검증, 다음 분기 평가. 실제 청산 봉 종료가 경계 이상이면 제외.
- 모델: 기존 32시간×5개 입력 MLP/CNN, 시드 17/29/43. 크기·정규화·옵티마이저 유지.
- 학습: 최대 100 epoch, patience 10, 검증 손실 최소 체크포인트 복원.
- 변경: 사건별 절대 순수익 `abs(net_return)`으로 BCE를 가중한다.
  학습 가중치는 학습 사건만으로 계산하고 평균 1로 정규화한다.
  검증도 검증 사건의 가중 BCE로 조기 종료하되 학습에 전달하지 않는다.
  순수익 0인 사건의 가중치는 0이다. 총 가중치가 0이거나 비유한 값이면 실패 처리한다.
- 점수: 일반적인 승률로 해석하지 않는다. 일정 입력에서 가중 BCE의 이상적 최적값은
  `E[r+ | x] / (E[r+ | x] + E[(-r)+ | x])`이므로 `점수 > 0.50`일 때만 진입한다.
  분포 이동·오차·계좌 고점 차이로 실제 조건부 기대 수익이 양수임을 보장하지 않는다.
- 상수 대조: 학습 양수 손익 합계 / 학습 절대 손익 합계에 같은 0.50 기준 적용.
- 비교: 원래 돌파·현금·가중 상수·비가중 16/17 모델. 동일 시각·원금·비용으로 대조한다.
- 평가: 기존 4개 비용/지연 시나리오. 같은 연속 블록 안에서는 분기를 넘어 계좌를 유지하되,
  결측으로 나뉜 22개 블록은 각각 독립 원금 100만 원으로 시작한다.
- 채택 조건: 기존 전 시드·비용 사전 기준 유지. 한 시드의 개선이나 거래 0회는 성공이 아니다.
  큰 수익 사건 과대 의존 여부, 놓친 수익/회피 손실을 추가 진단한다.
- 가중치 상위 1/5개 점유율과 사건 해시를 저장한다. 필요성을 느껴도 평가 결과를 보고 가중치를
  잘라 재평가하지 않는다. 그런 변경은 별도 후속 실험으로 기록한다.
- 운영 전략·Config Server·계좌·DB·배포는 변경하지 않는다. 새 홀드아웃으로 표현하지 않는다.

학습 구간만 미리 점검했을 때 단일 사건의 절대 손익 가중치 점유율은 약 2.04~5.33%,
상위 5개는 약 9.44~23.02%였다. 겹치는 사건 때문에 실제 공통 가격 움직임의 집중도는 더 높을 수 있다.
이 수치는 학습의 성공 또는 가중 목적의 효과를 입증하지 않는다.

구현 참고: [PyTorch BCEWithLogitsLoss 공식 문서](https://docs.pytorch.org/docs/2.14/generated/torch.nn.BCEWithLogitsLoss.html).
`weight`를 통한 사건별 가중과 클래스별 `pos_weight`를 혼동하지 않는다. 조건부 손익 점수의 식은
본 실험의 가중 목적에 대한 수학적 해석이지, 해당 문서가 거래 수익성을 보장한다는 뜻이 아니다.

## 재현 명령

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_meta \
  --source data/regime-08-2020-2026-public \
  --output outputs/breakout-meta-experiment-19 \
  --validation-quarters 2 --loss-weighting absolute-return
```

손익 가중치 및 학습·검증 표본 해시, 집중도와 상수 예측은 `seed-*/audits.json`에 저장한다.
모델 메타데이터 `loss_weighting=sample`은 점수가 일반 승률이 아님을 구분한다.
검증 가중치는 검증 집합 안에서 평균 1로 정규화하고 학습 집합의 가중치·정규화에 사용하지 않는다.

실행 후 결과는 [실험 19 결과](breakout-meta-results-19.md)에 기록했다.
