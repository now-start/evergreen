# 실험 47 — 손실 청산에만 채널 리셋 대기

## 사전 고정 계획

[실험46 후속 계획](breakout-entry-stop-adaptive-trail-reset-46.md)의
`entry-stop-loss-reset` 하나를46과 비교한다. 수익 보호 청산 이후의 새 돌파를 허용하여
상승 추세를 다시 포착할 수 있는지 평가한다. 재진입으로 반복 손실·비용이 늘 수도 있다.

- 46의 진입·초기 손절·가변 추적/청산선 하향 금지·두 종가 확인을 유지한다.
- 추가 청산만 성립한 주문이 실제 매도되면, 방금 끝난 거래의 순손익을
  `매도 체결가×수량−매도 수수료−매수 체결가×수량−매수 수수료`로 계산한다.
  체결가는 슬리피지 반영 가격. 원시 시가·미실현 손익·계좌 전체 손익을 대신 사용하지 않는다.
- 순손익>0이면 채널 리셋 대기 없음. 순손익≤0이면46과 동일하게 대기한다.
  실제 매도 봉의 확정 종가부터 새로운 원래 돌파 신호를 평가하며, 자동 즉시 매수는 없다.
- 새 신호·다음 시가·추가1시간 지연·최소 주문 조건은 그대로다.
  미체결이면 잠금 판단/상태 초기화 없음. 새 실제 매수 때 고점·TR·청산선 재설정.
- 일반/동시 채널 청산은 기존처럼 잠금 없음, 위험 주문은 영구 중단 유지.
  이후 손익이나 원래 전략의 미래 청산 시각을 판단에 사용하지 않는다.
- 동일 공개 BTC/KRW 시간봉·200봉 워밍업·22개 독립 계좌 각100만 원.
  평가36,384/40,896시간(88.97%), 결측 보간 없음·계좌 내 분기 경계 상태 유지.
- 전액 다음 시가 체결, 편도 수수료0.05%·슬리피지0.1%, 최소5천 원·수량1e-8.
  기본/슬리피지2배/비용2배/추가1시간 지연. 위험 중단10%, 갭/비용으로 상한 보장 불가.
- 기존·현금·prior·46·후보440회. 기존/46 대조176개 전체 JSON 일치,
  입력/소스 SHA와 전체 체결 손익 정합성을 확인한다.
- 모든4조건에서 기존/prior 대비 대응 차이 중앙값>0, 수익 구간 과반,
  최악 낙폭≤10%, 위험 중단0, 기본 자연 청산10회 이상. 기준·상수 사후 변경 없음.
- 반복 관찰한 자료의 탐색이며 새 홀드아웃·딥러닝 학습이 아니다.
  합산 손익은 단일 계좌 누적/연환산 수익이 아니다. 운영·설정·DB·배포 변경 없음.
- 사용자 지시로 독립 리뷰는 생략하고 자체 검증은 유지한다.

## 다음 사전 명시 실험 48 — 수익 청산 후 재진입에만 두 봉 확인

후보 하나 `entry-stop-confirmed-profit-reentry`를47과 비교한다. 손익 기준이나 추적 거리는
그대로 두고, 수익 청산 후 채널 리셋 전에 재진입하는 경우에만 추가 확인을 요구한다.

- 47의 초기 손절·가변 추적/하향 금지·청산 두 종가·순손실 채널 리셋은 동일하다.
- 추가 청산만으로 실제 매도하고 비용 차감 순손익>0이면 재진입 확인 상태를 켠다.
  순손익≤0이면47과 같은 채널 리셋 잠금. 일반/동시 채널 청산은 추가 확인 상태 없음.
- 확인 상태에서는 실제 매도 시각 이후 시작한 두 연속 확정 봉이 각각 원래 독립 돌파
  조건을 충족해야 매수를 예약한다. 두 봉은 각각 자신의 이전168봉 최고가×1.001을
  엄격하게 넘어야 하며, 이전 매수 신호의 돌파선을 고정해서 사용하지 않는다.
- 매도 전 봉은 세지 않는다. 실제 매도 봉도 포함 가능. 동률/실패는 연속성을 끊고
  다음 봉부터 다시 평가한다. 확인 완료 뒤 다음 시가(+지연1시간)에 매수한다.
- 확인 상태에서 종가가 이전48봉 최저가를 엄격하게 하회하면 확인 상태를 해제한다.
  해제 봉에서는 매수하지 않고 다음 봉부터 원래 한 봉 진입 조건으로 돌아간다.
  실제 새 매수에서도 확인 상태 해제. 미체결이면 상태 보존, 새 체결 기준 초기화는 기존대로.
- 위험 중단/예약 우선·계좌 고점·최소 주문 조건 유지. 손익과 확인 상태를 이용해
  계좌 손실을 초기화하거나 위험 중단 후 재진입하지 않는다.
- 동일 자료·200봉 워밍업·22계좌·4조건·모든 기준 유지.
  기존·현금·prior·47·후보440회, 기존/47 대조176개 전체 JSON 일치 요구.
