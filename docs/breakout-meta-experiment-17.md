# 실험 17: 승률 50% 대신 학습 손익 규모 반영

## 실행 전 고정 계획

이익과 손실의 크기가 다른 돌파 거래에서는 승률 50%가 손익분기 기준과 같지 않을 수 있다.
실험 16과 같은 학습 6분기·검증 2분기, 모델·시드·표본·비용·가격 구간을 유지하고
**진입 기준만 학습 사건의 평균 이익/손실로 결정**한다. 평가 구간의 성과를 보고 조정하지 않는다.

- 학습 경계 전에 실제 청산까지 완료된 동일 학습 사건만 사용한다. 사건 시각·레이블 해시 일치 필수.
- 양수 사건의 평균 순수익을 W, 0 이하 사건의 평균 손실 크기를 L이라고 하면 기준은 L/(W+L).
- 모델 점수가 이 기준보다 클 때만 원래 돌파 진입을 허용한다. 상수 예측 대조군에도 같은 기준을 적용한다.
- 두 결과 클래스가 모두 있어야 하며 기존 최소 표본·비중첩 조건을 유지한다.
- 이는 확률이 정확하고 미래 이익/손실 규모가 학습 평균과 같다는 가정의 단순 근사다.
  미보정 신경망 점수, 겹치는 사건, 큰 수익 사건, 시기 변화에 민감하다. 최적 임계값을 주장하지 않는다.
- 모델을 같은 시드로 다시 학습하고 실험 16 체크포인트와 동일한지 확인해 기준 변경 효과를 구분한다.
- 기본 비용으로 기준을 고정한 뒤 추가 비용·지연 조건을 평가하며, 비용별로 기준을 재최적화하지 않는다.
- 실험 15/16과 동일한 모든 시드·비용의 사전 채택 조건을 적용한다. 기존 관찰 자료의 탐색이다.
- 운영 전략·Config Server·계좌·DB·배포 변경 및 자동 실거래 승격은 없다.

```bash
  --source data/regime-08-2020-2026-public \
  --output outputs/breakout-meta-experiment-17 \
  --validation-quarters 2 --threshold-mode payoff
```
