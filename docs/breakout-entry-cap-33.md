# 실험 33 — 진입 돌파선 이격 상한

## 사전 계획

실험30~32의 조기 청산은 일관된 개선을 보이지 못했다. 실험32에서 원래72거래를
사후 분류했을 때 돌파선 위 이격이 진입 전24봉 평균 True Range 이하인34거래와
초과한38거래 모두 합산 손익이 양수였다. 초과 거래를 제외하면 좋은16거래도 잃는다.
따라서 단순 손익 분해가 아니라 상태를 유지한 전체 경로로 진입 제한을 검증한다.

- 후보 하나 `entry-cap-tr24`. 원래 `종가 > 이전168봉 최고가 ×1.001` 진입을 유지하되
  `종가 - 이전168봉 최고가 ≤ 신호 봉 이전24봉 True Range 단순 평균`일 때만 허용한다.
  같은 값은 허용한다. True Range는 `max(고가-저가, |고가-이전종가|, |저가-이전종가|)`.
  신호 봉은 제외하고 첫 True Range의 이전종가를 위해25번째 과거 봉까지 참조한다.
- 24시간·배수1 고정. 결과를 보고 배수나 기간을 재선택하지 않는다. 0변동 폭에서는
  실제 돌파 신호가 이격 상한을 통과할 수 없다. 승인만으로 원래 돌파 조건을 우회하지 않는다.
- 확정 신호 다음 시가 체결, 지연 스트레스에서는 한 시간 추가 지연. 보유 중 필터로
  청산을 제한하지 않는다. 원래48봉 저점 청산·10% 영구 위험 중단만 사용하며,
  실험30~32의 조기 청산·재진입 대기·위험 예산 필터는 후보에 결합하지 않는다.
- 기존·현금·prior와 실험30~32 후보도 대조로 실행한다. 기존·1시간·2시간·변동 폭
  청산 대조352개 전체 JSON이 실험32와 같아야 완료 처리한다. 변동 폭 계산은 실험32와
  같은 연구용 함수로 공유하며, 소스 해시와 대조 재현으로 변경 영향을 확인한다.
- 같은 원자료SHA·22개 연속 구간·200시간 워밍업·36,384/40,896시간(88.97%).
  구간별 독립 원금100만 원, 구간 내부 분기 경계는 상태 유지, 결측 보간 없음.
  각 매수·매도 수수료0.05%, 슬리피지0.1%, 최소 주문5천 원, 수량 단위0.00000001.
- 기본·슬리피지2배·수수료와 슬리피지2배·추가1시간지연 모두 기존 대비 대응 수익률
  차이 중앙값>0, 수익 구간 과반, 최대 낙폭≤10%, 위험 중단 없음, 기본 자연 청산10회
  이상이 필요하다. 위험 중단은 지연·갭·비용을 포함한 실제 손실 상한 보장이 아니다.
- 이미 반복 관찰한 과거 자료의 탐색이다. 새 홀드아웃이나 딥러닝 학습이 아니며,
  합산 독립 손익을 단일 계좌 누적·연환산 수익으로 표현하지 않는다.
  실거래·Config Server·DB·배포·버전·커밋·푸시는 변경하지 않는다.

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_confirmation \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/breakout-failure-buffer-32 \
  --output outputs/breakout-entry-cap-33 \
```

### 실패 원인과 배운 점

- 기본 완결 거래72→62건, 수수료75,691→64,354원, 모형상 슬리피지151,383→128,709원.
  거래 비용은 줄었고 기본 위험 중단도4→1구간으로 감소했지만 수익성 개선은 일관되지 않다.
- `block-011`의 개선430,404원을 제외한 나머지21구간 합산 차이는 **-74,824원**이다.
  이 구간은2024-01-11의 큰 손실 진입을 피하면서 이후 영구 중단을 피한 효과가 크다.
  추가 체결 지연에서는 해당 구간의 개선이52,931원으로 줄고 전체 합계도 기존보다 낮다.
- `block-009`는 기존 +109,358원에서 후보 +9,226원으로 악화됐다. 예를 들어
  기존2023-09-28 진입은 +6,375원이었지만 후보는2023-10-02에 늦게 진입해 -42,061원이다.
  10월23일의 수익 진입도 늦어졌다. 날짜는 UTC이고, 체결 금액에는 경로별 자본 차이도 있다.
- 후보62거래 중34개는 기존과 진입 신호가 같고,24개는 기존 보유 구간 안에서 늦게 진입,
  나머지4개는 다른 새 거래다. 늦은24개 모두 기존보다 높은 기준 시가에 샀다.
  돌파선 자체가 올라가면 이격이 작아져 나중에 필터를 통과할 수 있어, 이 제한은
  단순한 저가 매수가 아니다. 다만 이24개 중14개는 수익이고 합산 +499,567원이므로
  늦은 거래를 모두 제거하면 좋아진다고 결론내릴 수도 없다.
- 남은 위험 중단은 `block-003`이다. 계좌는 원금100만 원에서 평가 고점1,107,692원을
  기록했으나 두 거래 이후996,529원이 되어 고점 대비10.04% 감소했다. 최종 원금 손실
  -0.35%와 고점 대비 낙폭은 다르다. 진입 제외만으로 보유 이익 반납을 막지 못했다.
- 보조 사후 진단으로 원래72거래의 신호 전24시간 방향 효율
  `(마지막 종가-첫 종가)/절대 종가 변화 합`을0.5 이상으로 나누면 해당 거래는3개뿐이며,
  1개 수익·합산 -21,178원이다. 나머지는69개·32개 수익·합산 +1,210,697원이다.
  표본이 빈약하므로 이 조건을 다음 후보로 바로 채택하지 않는다. 필터 적용 후 손익은 아니다.

### 다음 사전 명시 가설 — 보유 가격 고점 추적 청산

실험34는 이격 필터를 제거하고 원래 돌파 진입을 유지한다. 후보 하나는 **실제 매수 이후
관측한 최고 종가(매수 시가 포함)에서 진입 신호 전24봉 평균 True Range의3배를 뺀 가격**을
추적 청산 기준으로 삼는다. 종가가 기준 미만이면 다음 시가 매도하며, 같으면 매도하지 않는다.
변동 폭은 원래 매수 신호 시점에 고정하고 실제 매수마다 다시 계산한다. 지연 체결에서도
신호 봉은 제외한다. 봉 고가로 장중 경로를 추정하지 않고, 실제 체결 이후 확정 종가만
최고가에 반영한다. 평균 변동 폭이0이면 이 추가 청산은 적용하지 않는다.

48시간 저점 청산·10% 영구 위험 중단은 유지하고, 진입 제한·실험30~32 청산은 결합하지
않는다. 24시간·3배는 사전에 고정한 한 후보이며 최적 배수라는 주장이 아니다. 체결·비용·
원자료·구간·평가 기준은 동일하다. 짧은 변동 폭이 잦은 청산과 수익 기회 상실을 낳을 수
있으므로 비용·지연을 포함한 전체 경로를 비교한다. 아직 구현·실행하지 않은 가설이고,
이번 결과로 유리한 배수를 역선택하거나 해당 손실 구간만 예외 처리하지 않는다.
