# 실험54 — 청산 연장 시작 시 저점 상승 확인

## 실행 전 계약

53에서 고정한 계획을 실행한다. 정책50의 첫 추가 청산 결정에서 긴 추세51도 청산이면
그대로 매도한다. 그렇지 않고 직전24봉 저점 최솟값이 이전24봉 저점 최솟값보다
엄격히 높을 때만 현재 포지션을51 방식으로 연장한다. 현재 결정 봉은 제외한다.
동률/하락이면50 청산을 유지하며, 같은 포지션에서 연장 허가를 다시 판단하지 않는다.

53의24시간 중간 점검은 사용하지 않는다. 초기 손절·48봉 채널·계좌 위험 중단과
진입 예산은 유지한다. 새 실제 매수/매도에서 포지션 상태만 초기화하며, 계좌 잔고·
고점·영구 위험 중단은 유지한다. 거절된 청산 이후에도 새 연장 사건을 만들지 않고
기존 청산 재평가/위험 절차를 따른다.

기존22개 연속 평가 계좌·200시간 워밍업·100만원 초기 자금·36,384시간 커버리지,
기본/슬리피지2배/비용2배/체결1시간 지연 조건을 재사용한다. 기존·50·51의 전체
JSON 재현성을 확인한다. 비용 차감 후 기존 대비 계좌별 차이 중앙값>0, 절반 초과
양수 계좌, 최대 낙폭10% 이내·중단0개·기본 정상 청산10개 이상을 그대로 적용한다.

현재 자료는 이미 본 탐색 자료다. 파라미터 검색이나52의 사후 레이블 사용, 모델 학습,
실거래·설정 서버·DB·배포·버전·커밋 변경은 하지 않는다. 독립 리뷰는 요청대로 생략한다.

## 재현성과 검증

53과 공통 실행기를 사용하되 `--higher-low`로 중간 점검 없이 저점 상승 조건을 켠다.

```sh
.venv/bin/python -m evergreen.research.experiments.breakout_exit_checkpoint \
  --higher-low \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/breakout-entry-stop-trend-context-51 \
  --output outputs/breakout-exit-higher-low-54
```

실행 종료0, `completed_partial_coverage`, `live_enabled=false`이며 세 연구 후보의
전체 게이트는 모두false다. 원래 평가 커버리지88.97%와200봉 워밍업을 유지했다.
기존/50/51 ×4조건 ×22계좌의264개 전체 JSON이 대조 산출물과 일치한다.
입력533개·공개 원본321개·소스67개 해시를 재검사했고,528개 결과의 체결 손익 합과
최종 자산 차이가0.000001원 이내 일치했다. 최종 미청산 BTC·체결 수량 불일치 없음.

신규11개와52·53 및 공통 실행기 회귀를 합한46개 테스트가 통과했다(35.69초).
구현 전 최초9개의 실패를 확인했다. 두 비교 구간 경계, 현재 봉 제외, 동률,
긴 추세 우선순위, 위험 청산, 거절 후 같은 포지션 재판단 방지,192봉 최소 이력,
옵션 충돌 및 대조 전체 결과 변조 시 실패 처리를 검증했다.
추가로53 후보의22계좌×4조건,88개 전체 결과를 재생해 변경 전 JSON과 일치함을
확인했다. 전체674개 통과·22개 건너뜀(299.95초), 커버리지88.37%로80% 기준을
충족했다. 건너뛴 항목은 일회용 MariaDB 미설정 통합 테스트다.
Ruff·200파일 포맷·mypy67개 소스·`git diff --check`도 통과했다.
검증 도구의 통과는 수익성 게이트 통과가 아니며, 이번 후보는 네 조건 모두 탈락했다.

## 후속 실험55 사전 계획 — 연장 가격 이탈의 두 종가 확인

53의 시간 점검과54의 과거 저점 허가 조건은 제거한다. 다음에는50의 첫 추가 청산에서
긴 추세가 아직 매도하지 않으면 현재 포지션을 연장하되, **그 결정 종가를 고정 기준으로
삼아 이후 두 개의 연속 확정 종가가 모두 그 아래이면** 청산을 예약한다.
이상/동률로 회복하면 연속 횟수는0으로 돌아간다. 원래 결정 봉은 기준과 같으므로
이탈 횟수에 포함하지 않는다.

가설은 과거 구조의 허가/거절보다 실제 연장 이후의 연속 악화를 확인하는 편이
불리한 연장을 일찍 줄일 수 있다는 것이다. 기존 두 종가 확인 방식과 동일한2회를
고정하며 시간·가격 완충 임계값을 추가 탐색하지 않는다. 하루 뒤 한 번만 평가하는
53과 다르게 매 확정 봉을 보며, 회복 후에도 이후 연속 이탈을 계속 관찰한다.

긴 추세가 처음부터 청산하면 그대로 매도한다. 연장 중에도 초기 손절·48봉 채널·위험
청산이 먼저 발생하면 유지한다. 두 종가로 예약된 청산을 후속 반등으로 취소하지 않고,
최소 주문 거절 시 실제 청산까지 재시도한다. 실제 체결 후에만 포지션 상태를
초기화하고 계좌 잔고·고점·위험 중단은 보존한다. 이 가격 기준이10% 최대 손실을
보장한다고 가정하지 않고 지연·갭·비용을 포함해 그대로 검증한다.

기존/50/51·동일22계좌·네 조건·기존 수익/위험 게이트를 유지하고,52의 사후 레이블은
사용하지 않는다. 새 계좌 경로 전체를 재생한다.55는 이 문서 시점에는 계획만
고정했으며 구현·실행하지 않았다. 수익성 목표는 아직 달성하지 못했다.
