# 실험 30 — 진입 당시 돌파 실패 청산

## 사전 계획

실험 29는 위험 여유를 확인해 중단을 줄였지만 기본·지연 조건의 합산 수익성이 악화됐다.
이번에는 최초 진입을 그대로 두고 실패한 돌파를 일찍 종료한다. 기존 72개 거래의
사후 진단에서 실제 매수 후 기존 청산 전 종가가 진입 신호 당시 이전168봉 최고가
아래로 돌아온 거래는 49건 중 19건 수익, 기존 합산 손익 +502,277원이었다.
나머지는 23건 중 14건 수익, +687,242원이었다. 이 분류는 미래 경로를 관찰한
오류 분석이며 매수 필터로 사용하지 않는다. 조기 청산 시 회복 수익도 잃을 수 있다.

- 후보 하나 `failed-breakout`: 매수 신호 당시 이전 168개 봉 최고가를 고정 기준으로
  저장한다. 신호 봉의 고가는 제외하고 기존 진입 버퍼 0.1%는 이 청산 기준에 붙이지 않는다.
- 실제 보유 중 확정 종가가 고정 기준보다 작으면 매도한다. 같은 값이면 이 조건으로
  청산하지 않는다. 기존 48봉 저점 청산과 10% 영구 위험 중단도 그대로 유지한다.
- 기준은 새 고점에 따라 올리지 않고 실제 매수마다 다시 잡는다. 매수 체결이 없는
  신호는 보유 상태를 만들지 않는다. 추가 1시간 지연에서도 실제 체결의 원래 신호로 계산한다.
- 매도는 다음 시가(지연 스트레스는 추가 1시간 후)에 실행한다. 기준 가격이나 봉 저가에
  소급 체결하지 않는다. 갭과 비용 때문에 낙폭 10%를 보장하지 않는다.
- 기존 168봉 고점 ×1.001 매수 조건을 유지한다. 실험 24~29의 다른 진입/청산 조건과
  혼합하지 않는다. 별도 재진입 대기를 두지 않아 회전율·왕복 비용이 늘 수 있다.
- 실험 29와 같은 원자료 SHA, 22연속 계좌, 200시간 워밍업, 36,384시간을 비교한다.
  계획40,896시간 대비88.97%, 결측 보간 없음, 연속 구간의 분기에서 계좌 유지.
  각 구간 독립 원금100만 원으로 단일 누적 계좌가 아니다.
- 기본, 슬리피지2배, 수수료·슬리피지2배, 추가1시간지연을 원래 돌파·현금·중복 대조
  `prior`와 비교한다. 기존 돌파 88개 전체 결과의 실험29 재현 대사를 요구한다.
- 네 조건 모두 기존 대비 대응 수익 차이 중앙값>0, 수익 구간 과반, 최악 낙폭≤10%,
  위험 중단 없음, 기본 자연 청산≥10회를 요구한다. 수익 없는 위험 감소는 채택하지 않는다.
- 이미 반복 관찰한 자료의 탐색이지 새 홀드아웃이 아니다. 모델 학습 없음.
  실거래·Config Server·DB·배포·버전·커밋·푸시 변경 없음.

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_confirmation \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/breakout-budget-29 \
  --output outputs/breakout-failure-30 \
  --failed-breakout-exit
```

### 실패 원인

- 기본 조건의 완결 거래는 72→117건, 자연 청산(결산 제외)은 69→115회로 증가했다.
  수수료는 75,691→119,918원, 모형상 슬리피지 비용은 151,383→239,838원이다.
  포지션 경로와 거래 수량도 달라지므로 비용 차이만으로 성과 차이 전체를 설명하지 않는다.
- `block-014`는 4→11거래, 기존보다 173,154원 악화됐다. 2024-11-06 진입을
  기존 전략은 11-25까지 유지해 +301,561원을 기록했다. 후보는 같은 최초 진입을
  11-06에 -12,181원으로 청산한 뒤 두 번 더 손실을 내고 11-08에 재진입했다.
  최종 상승을 일부 잡았지만 반복 청산·재진입으로 수익이 줄었다. 날짜는 UTC다.
- `block-011`에서는 첫 손실 축소로 영구 중단을 피한 뒤 상승 구간에 참여하여
  기존보다 322,236원 개선했다. 그러나 다른 21구간의 합계 차이는 -449,503원으로
  이 개선을 상쇄했다. 손실 방어가 일부 구간에서 효과적이어도 전체적으로 우월하지 않다.
- 즉시 청산은 정상적인 돌파선 재시험까지 실패로 간주했다. 최대 낙폭 10% 초과와
  지연 조건의 추가 악화도 남아 있다. 위험 중단 횟수 감소만으로 승격하지 않는다.

### 다음 사전 명시 가설

돌파선 아래 **두 개 연속 보유 중 확정 종가**를 요구하면 한 시간 이탈에 따른
불필요한 청산을 줄일 수 있는지 시험한다. 후보는 하나만 두고 1/2/3시간 그리드 탐색은
하지 않는다. 기준 이상 종가나 실제 새 매수에서 연속 횟수를 초기화하고, 매수 이전 봉은
세지 않는다. 기존 48시간 청산·위험 중단은 기다리지 않고 유지한다. 지연 체결, 재진입,
비용·구간·승격 기준은 동일하다. 아직 구현·실행하지 않은 가설이며 미관측 검증이 아니다.

운영 전략·Config Server·DB·배포는 변경하지 않았다. 이 후속 실험 변경은 미커밋 상태다.

검증: 전체 테스트 377개 통과·22개 생략(일회용 MariaDB 환경 미설정), 커버리지89.07%.
Ruff·mypy(64개 소스)·diff 공백 검사 통과. 시그널 봉 제외, 진입 기준 고정·재설정,
동일 가격 경계, 실제 체결 지연, 미래 봉 불변성, 원래 청산 유지, 최소 주문 거절,
실험 조건 혼합 거절, 파이프라인 연결·대조 불일치 거절을 테스트했다.

독립 리뷰: Spark 사용량 제한으로 허용된 GPT-5.5 읽기 전용 CLI 리뷰를 수행해
`APPROVE`를 받았다. 시간 참조·체결 상태·실험 연결·보고서에 수정 필요 사항은 없었다.
이는 코드 검토 승인이지 전략 채택 승인이 아니다.
