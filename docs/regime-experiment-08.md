# 실험 08 — 장기 데이터와 장세별 전략 전환

## 결과 확인 전 고정한 계약

- 목적: 고정 돌파보다 장세 전환이 비용 차감 성과와 위험을 개선하는지 검증한다.
- 범위: 오프라인 공개 BTC/KRW 시간봉만 사용. 운영 DB, 키, Config Server, 실거래 코드는 변경하지 않는다.
- 수집: 2020-01-01~2026-09-01 UTC, 분기별 169시간 워밍업 포함. 마지막 분기는 7~8월이다.
- 결측: 원본 응답·실패를 보존하고 해당 분기는 제외한다. 보간·기간 재선택·수익률 0 대체 금지.
- 학습: 각 평가 분기 이전 최대 8개 달력 분기 중 마지막 분기는 조기 종료 검증,
  나머지 품질 통과 분기는 학습. 직전 검증 분기가 결측이면 해당 평가의 모델 학습도 중단한다.
- 평가: 2022-01-01 이후 분기를 순서대로 평가한다. 2026년은 과거 실험에서 일부 관찰했으므로
  완전히 새로운 최종 홀드아웃으로 주장하지 않는다. 결과로 임계값·전략을 재선택하지 않는다.
- 레이블: 다음 시가부터 24시간 후 시가까지 로그 수익률. 신호 시점 직전 24시간 변동성 × sqrt(24)와
  기본 왕복 비용 0.3% 중 큰 값을 경계로 상승/보합/하락을 구분한다. 레이블 완성 시각은 분할 경계보다
  엄격히 앞서야 한다. 미래 레이블을 전략 입력으로 사용하지 않는다.
- 모델: 기존 32×5 인과적 차트 특성, MLP 160→32→16→3, CrossEntropyLoss,
  학습 표본만 정규화, CPU, seed 17, 최대 100 epoch, patience 10, 검증 손실 최소 가중치 복원.
  분류 점수 0.55 미만은 불확실로 처리하며 보정된 확률이라고 주장하지 않는다.
- 규칙 장세: SMA48/SMA168 비율이 1.01 초과면 상승, 0.99 미만이면 하락, 그 외 보합.
- 전환: 3개 연속 확정 봉의 동일 판단, 전환 후 6시간 유지. 초기 상태는 불확실.
- 상승: 기존 168시간 돌파. 보합: 기존 24시간 밴드 평균회귀. 하락: 신규 진입 금지·보유 청산.
  불확실: 신규 매수 보류. 상승/보합 전환 중 보유분은 최초 진입 규칙이 청산을 책임진다.
  공통 낙폭 중단은 언제나 우선한다.
- 비교군: 현금, BTC 보유, SMA48/168, 기존 돌파, 규칙 장세 전환, MLP 장세 전환.
- 비용: 모의 원금 100만 원, 편도 수수료 0.05%·슬리피지 0.1%; 기본/슬리피지 2배/
  전체 비용 2배/한 봉 추가 지연. 기존 공통 체결·낙폭 엔진을 재사용한다.
- 보고: 분기 독립 원금 결과와 데이터·모델이 이어지는 연속 블록의 원금 유지 결과를 별도 기록.
  블록 안에서는 분기 재학습 때 잔고·고점·위험 중단을 초기화하지 않는다. 결측 사이 수익은 연결하지 않는다.
- 분류 평가: 혼동 행렬·macro F1·다수 클래스 기준선·클래스 수·예측 분포와 학습 손실을 저장한다.
- 연구 통과: 모든 연속 블록의 네 비용 조건에서 MLP 전환 수익 > 0, 낙폭 ≤10%, 중단 없음,
  돌파와 규칙 전환 수익 모두 초과, 기본 청산 합계 ≥10. 결측 평가가 하나라도 있으면 전체 검증 미완료.
  통과해도 자동 승격 없음. 단일 시드·반복 관찰 자료·봉 단위 위험 관측의 한계가 남는다.

## 데이터 품질 확인 후 추가한 탐색 08b (성과 확인 전)

2020~2026년 27분기 모두 워밍업 또는 평가 구간에 1~9개 결측이 있어 원안 08의 평가가 불가능했다.
원안은 실패로 유지한다. 08b는 수익 확인 전에 다음 결정적 분할 규칙을 추가한 별도 탐색이다.

- 원본 응답의 SHA256과 요청 상태를 검증한 뒤 전체 기간을 합치고, 가격 충돌을 거부한다.
- 모든 결측 시각을 기록하고 연속 블록으로 분리한다. 각 블록 첫 169시간은 워밍업으로만 사용한다.
- 분기 단위 학습/검증/평가 경계는 유지하되 각 블록 내에서만 특성과 레이블을 계산한다.
  학습은 직전 8개 달력 분기의 앞 7개, 검증은 직전 1개 분기. 결측을 건너는 레이블은 만들지 않는다.
- 각 평가 분기와 블록의 교집합 중 워밍업 후 24시간 이상인 모든 구간을 공통 비교한다.
  분기 경계에서도 모델을 고정한 시점 이전 레이블만 사용한다. 학습 불가능한 분기는 제외 사유를 기록한다.
- 별도로, 인접 평가 구간을 합친 연속 블록에서도 원금·고점·위험 중단·진입 전략을 유지하여 평가한다.
  결측/모델 없는 구간은 연결하지 않는다. 종료 정산은 관측된 마지막 가격에서 모의로 수행한다.
- 완전한 2020~2026년 연속 운용 수익, 결측 중 체결, 완전히 새로운 홀드아웃 성과로 해석하지 않는다.
  08의 전체 검증 통과는 false로 유지하며 08b는 Paper 검증 후보를 찾는 탐색 결과만 제공한다.

## 실행

서버 부트스트랩이나 Config Server를 사용하지 않는다. 수집만 공개 API 네트워크 접근이 필요하다.
출력 디렉터리는 매 실행 새 경로를 지정하며 기존 결과는 덮어쓰지 않는다.

```bash
uv run python -m evergreen.research.experiments.regime_data --output data/regime-08-public
uv run python -m evergreen.research regime-study --source data/regime-08-public --output outputs/regime-08-run
```

`protocol.json`에 소스 해시·규칙을, `datasets/coverage.json`에 원본 해시·결측 시각을 저장한다.
`folds/*/model/`에는 최적 가중치·정규화·epoch별 손실·분할 시각이 있으며,
`predictions.json`과 `classification.json`에는 실제 다음 분기 예측과 혼동 행렬이 있다.
모델은 매 분기 시작 시 이미 학습 완료됐다고 가정한다. 학습·배포 지연은 실제로 측정하지 않았고
한 시간 체결 지연 시나리오는 이를 정확히 재현하는 보장이 아니다.
두 전환 전략은 각 독립 평가 시작에서 불확실 상태로 시작하며 동일한 3봉 확인을 적용한다.

## 실행 결과 — 2026-09-09

공개 시간봉 58,519개(2020년 이전 워밍업 포함)를 확보했다. 전체 범위의 결측은 90시간이다.
평가 대상 2022-01-01~2026-09-01의 40,896시간 중 37,066시간(90.63%)을 평가했다.
나머지는 결측·블록별 워밍업·24시간 미만 평가 조각이다. 제외 구간을 0%로 처리하지 않았다.

19개 분기 MLP를 실제 학습했다. 최적 복원 epoch는 1~14, 종료 epoch는 11~24였다.
분기 조각 29개와 원금 유지 연속 블록 22개 × 6전략 × 4비용/지연 조건으로 총 1,224개 모의 결과를
생성했다. 분기 조각과 연속 블록은 같은 자료를 다른 운용 단위로 비교한 것이며 독립 표본 수가 아니다.

아래는 **22개 독립 원금 블록의 기본 비용 결과 분포**다. 전체 기간 누적·연간 수익률이 아니다.

| 전략 | 순수익률 중앙값 | 최저 블록 수익률 | 최악 블록 낙폭 | 수익 블록 |
|---|---:|---:|---:|---:|
| 현금 | 0.00% | 0.00% | 0.00% | 0/22 |
| BTC 보유 | -0.17% | -34.58% | 40.55% | 11/22 |

전체 비용 2배 조건에서 돌파 중앙값은 +0.19%, MLP 전환은 -9.58%였고 MLP의 양수 블록은 0/22였다.
기본 비용의 MLP는 청산 286회, 위험 중단 14블록이다. 돌파도 청산 73회, 중단 4블록으로
장기 수익성이나 위험 기준을 전부 통과한 전략은 아니다.

### 모델 오류 분석

분류 평가 36,370개 중 실제 레이블은 하락 5,812 / 보합 25,209 / 상승 5,349개다.
반면 argmax 예측은 하락 143 / 보합 36,130 / 상승 97개로 **99.34%가 보합**이었다.
이는 0.55 신뢰도 필터 이전의 분류 결과이며, 실제 전략 입력에는 불확실 처리와 전환 안정화가 추가된다.
분기 정확도는 64~77%지만 대부분 학습 다수 클래스만 예측하는 기준선과 비슷했고 macro F1은
0.262~0.327이다. 높은 보합 비중 때문에 정확도만으로 장세 분류 능력이 있다고 볼 수 없다.
모델이 보합 중심으로 예측해 평균회귀 전략으로 편중되는 것이 관측됐으나,
손실 전체를 분류 오류 하나의 원인으로 확정할 수는 없다. 다음 실험은 보합=현금 대조군과
클래스 균형 학습을 별도로 고정해 효과를 분리하는 방향이 적절하다. 이 후속 실험은 아직 실행하지 않았다.

### 재현·검증·결론

- 원실행: `outputs/regime-experiment-08b/`; 최종 코드 재실행: `outputs/regime-experiment-08b-verified/`.

  규칙 전환의 시작 확인을 MLP와 대칭으로 맞추면서 1블록의 세부 결과가 바뀌었으며 최종 보고는 재실행 기준이다.
