# 실험 37 — 단기 변동 폭 확대 확인 후 돌파 진입

## 실행 전 고정 계획

실험35~36의 상승 후 추적 청산은 상승 없이 손실로 이어지는 원래 진입을 바꾸지 못했다.
실험36에서 원래72개 거래를 분해했을 때 신호 이전 TR24>TR168인36거래의 합산 손익이
더 컸지만, 이는 필터 적용 결과가 아니며14개 수익 거래 누락과 확대 구간의 큰 손실도 있다.
이 가설을 새로운 매매·잔고·고점·위험 경로로 재실행한다.

- 후보 하나 `tr-expansion-24-168`. 원래 `종가 > 이전168봉 최고가 ×1.001`에 더해
  `이전24봉 평균 True Range > 이전168봉 평균 True Range`일 때만 매수를 허용한다.
  같은 값은 거절한다. 둘 다0이면 통과하지 않는다. 비율 나눗셈 없이 두 평균을 비교한다.
- 두 평균 모두 현재 신호 봉은 제외한다. TR은 `max(고가−저가, |고가−이전종가|,
  |저가−이전종가|)`이며168개 TR에는 이전종가용 봉과 신호 봉까지 최소170봉이 필요하다.
  기존200시간 워밍업을 유지하며24·168시간·배수1을 고정한다. 임계값 탐색 없음.
- 승인만으로 돌파 조건을 우회하지 않는다. 거절 후 미래의 독립 돌파 신호는 그 시점의
  과거 자료로 다시 판단한다. 첫 신호나 이전 거절 시점의 값을 고정해 재사용하지 않는다.
- 원래48시간 저점 청산·10% 영구 위험 중단 유지. 보유 중 필터로 청산을 막지 않는다.
  추적 청산·다른 진입 필터·조기 청산·재진입 대기와 결합하지 않는다.
- 다음 시가 전액 매수/매도, 지연 스트레스는 한 시간 추가. 매수·매도 각각 수수료0.05%,
  슬리피지0.1%, 최소5천 원, 수량 단위0.00000001. 높은 변동 폭에서 진입하면 갭·실제
  손실이 커질 수 있고10% 낙폭 중단은 실제 손실 상한 보장이 아니다.
- 같은 원자료SHA·22개 독립 연속 계좌·36,384/40,896시간(88.97%), 각 원금100만 원.
  구간 내부 분기 경계는 상태 유지, 결측 보간 없음. 대조는 기존·현금·prior·실험36.
  기존/실험36 전체176개 JSON 재현이 완료 조건이며 총440회 비교한다.
- 기본·슬리피지2배·비용2배·추가1시간지연 모두 기존 대비 대응 수익률 차이 중앙값>0,
  수익 구간 과반, 최악 낙폭≤10%, 위험 중단 없음, 기본 자연 청산10회 이상을 요구한다.
- 이미 반복 관찰한 자료의 탐색이며 새 홀드아웃·딥러닝 학습·실거래 성과가 아니다.
  손익 합계는 독립 계좌의 합계이지 전체 기간 단일 원금 누적 수익률이 아니다.
  실거래·Config Server·DB·배포·버전·커밋·푸시는 변경하지 않는다.
