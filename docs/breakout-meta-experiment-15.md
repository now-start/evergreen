# 실험 15: 실제 돌파 청산에 맞춘 거래 수익성 예측

## 실행 전 고정 계획

목표는 실제 돌파 진입 후보 중 비용 차감 후 유리한 거래를 구분하는 것이다.
실험 06은 12시간 보유 제한과 짧은 자료로 돌파 학습 표본이 부족했다. 이번에는 원래
168시간 고점 돌파 진입·48시간 저점 이탈 청산·10% 위험 중단을 그대로 사용한다.
실거래, 운영 설정, 계좌, DB, 배포는 변경하지 않는다.

- 원자료: 2020-01-01~2026-09-01 공개 시간봉. 결측을 보간하지 않고 연속 블록으로 분리.
- 학습 사건: 현금 상태라고 가정했을 때 돌파가 발생한 모든 시각. 진입은 다음 봉 시가.
- 레이블: 공통 백테스트 엔진의 해당 거래 순수익 > 0. 원금 100만 원,
  편도 수수료 0.05%·슬리피지 0.1%·최소 주문·수량 단위를 포함.
- 후보 하나만 진입을 허용하고 이후 재진입은 차단한다. 원래 전략 청산 또는 위험 청산까지
  추적하며, 블록 끝 강제 정산만 가능한 사건은 미완결로 기록하고 학습하지 않는다.
- 레이블 사용 가능 시각은 실제 청산 봉 종료 시각. 학습·검증 경계를 넘는 레이블은 제거.
- 각 사건의 계좌 고점은 새 원금 기준이다. 연속 운용의 기존 계좌 고점과는 다를 수 있다.
- 겹치는 사건은 독립 표본이 아니다. 기존 `sample_counts`의 보수적 비중첩 사건 수를 함께 기록.
- 7분기 학습/1분기 검증 후 다음 분기 평가. 2022년 이후 모든 적격 가격 구간을 포함.
- 학습 최소 50사건·비중첩 20개, 검증 최소 20사건·비중첩 5개, 두 클래스 모두 필요.
  부족한 분기는 모델을 만들지 않고 현금 대기하되 평가에서 해당 분기를 빼지 않는다.
- 기존 32시간 x 5채널 특성, 기존 MLP/CNN 구조, 시드 17/29/43.
- 최대 100 epoch·patience 10, 학습 자료만의 정규화, 검증 BCE 최저 모델 복원.
- 진입 임계값은 0.50 고정. 장세 예측이 아니므로 별도 장세 확인 3회/체류 6시간은 적용하지 않는다.
- 단순 대조군: 원래 돌파, 현금, 학습 사건의 양수 비율을 모든 진입에 사용하는 상수 예측.
- 가격 구간별 169시간 준비. 연속 구간 안 분기 모델 교체 시 잔고·고점·중단 상태 유지.
- 기본 비용, 슬리피지 2배, 비용 전체 2배, 추가 체결 지연 1시간을 같은 구간에서 평가.
- 후속 채택 조건: 모든 시드·비용에서 원래 돌파 및 상수 예측 대비 블록별 수익 차이
  중앙값 > 0, 양수 블록 > 절반, 최악 낙폭 ≤ 10%, 위험 중단 없음, 기본 청산 ≥ 10회.
- 기존에 관찰한 자료의 탐색이며 신규 홀드아웃이나 온라인 paper 결과가 아니다.
  가장 좋은 시드만 고르지 않으며 수익성과 실거래 승격을 보장하지 않는다.
