# 실험 24 — 청산 채널만 48시간에서 24시간으로 단축

## 실행 전 고정 계획

실험 23의 기본 비용 후보에서 위험 중단이 남은 구간은 2022년 7월과 2025년 11월 시작
구간이다. 진입 필터를 강화할 때 큰 수익도 놓쳤으므로, 이번에는 진입 모델을 더 변경하지
않고 청산 지연을 줄이는 별도 가설을 검사한다. 빠른 청산은 손실을 줄일 수도 있지만
추세 수익을 일찍 끊거나 재진입 비용을 늘릴 수 있다. 개선은 아직 미확인이다.

- 주 후보 하나: 원래 168시간 고점 돌파 진입 그대로, 이전 24시간 저점 이탈 시 청산.
  대조는 원래 48시간 저점 청산의 `breakout-v1` 및 현금이다.
- 현재 봉 저점은 채널 계산에서 제외하고 확정 종가가 채널 아래일 때 다음 시가에 주문한다.
  비용·1시간 추가 체결 지연·계좌 10% 영구 중단·전액 매매·종료 정산은 공통 엔진 그대로다.
- 24시간은 하루 채널이라는 단일 사전 선택이다. 다른 청산 기간·손절선·임계값을 탐색하지 않는다.
- 실험 23과 같은 공개 원자료 SHA, 200시간 워밍업, 22개 연속 계좌 구간을 사용한다.
  구간별 새 원금 100만 원이며, 분기마다 계좌나 위험 중단 상태를 초기화하지 않는다.
  원래 돌파의 모든 구간·비용 결과가 실험 23과 정확히 일치해야 비교를 인정한다.
- 학습·예측 변경 없음. 과거 48시간 청산에 맞춘 MLP 점수를 새 청산의 수익 확률로 재사용하지 않는다.
  이번은 규칙 청산의 분리 실험이며, 통과했을 때만 별도 계획으로 새 청산 레이블 모델을 검토한다.
- 기본/슬리피지 2배/수수료·슬리피지 2배/체결 1시간 지연을 모두 비교한다.
  원래 돌파 대비 대응 구간 수익 차이 중앙값 >0, 양수 구간 과반,
  최악 낙폭 ≤10%, 위험 중단 없음, 기본 비용 청산 10회 이상을 모두 요구한다.
- 수익률 중앙값, 대응 차이, 낙폭, 중단, 체결 횟수와 수수료를 함께 보고한다.
  기존 반복 탐색 자료이므로 통과해도 미관측 검증이나 실거래 수익을 입증하지 않는다.
- 연구용 백테스트 옵션만 추가한다. 운영 전략 카탈로그·실거래·Config Server·DB·배포·커밋·푸시 변경 없음.

## 재현

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_exit \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/breakout-ensemble-23 \
  --output outputs/breakout-exit-24
```

출력은 새 디렉터리여야 한다. `seed-17`은 공통 집계기를 재사용하는 계좌 결과 저장 슬롯이며
학습 시드가 아니다. `prior`는 원래 돌파와 같은 항상 진입 허용 대조로, 추가 모델이 아니다.
청산 기간은 개별 Result 스키마를 바꾸지 않고 실험 프로토콜과 `exit24` 파일명으로 식별한다.
