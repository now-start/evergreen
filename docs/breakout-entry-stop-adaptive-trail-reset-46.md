# 실험 46 — 상승 후 가변 추적 거리와 청산선 하향 금지

## 사전 고정 계획

[실험45의 후속 계획](breakout-entry-stop-profit-trail-reset-45.md)에 정한
`entry-stop-adaptive-trail-reset` 하나를45와 비교한다. 진입 직전의 작은 변동 폭 때문에
상승 추세를 조기 청산하는 경로가 줄어드는지 평가한다. 더 넓은 거리로 위험이 다시 커질 수 있다.

- 45의 원래 신호 이전24봉 TR·실제 매수 시가·초기 손절·두 종가·채널 리셋 유지.
- 최고가는 실제 매수 시가와 매수 이후 확정 종가만 사용한다. 활성은
  `고점≥매수 시가+3×진입 TR`. 0 진입 TR 비활성.
- 활성 이후 `고점−3×max(진입 TR24, 현재 봉 이전24봉 TR)`를 계산한다.
  현재 봉은 TR에서 제외한다. 실제 청산선은 `max(직전 청산선, 계산한 선)`이며
  초기값은 `매수 시가−3×진입 TR`. 이미 올린 선을 다시 내리지 않는다.
- 당시 청산선에 대한 두 연속 엄격 하회로 다음 시가 청산(+지연1시간 조건).
  동률/상회 리셋. 새 실제 체결에서 상태 재설정, 미체결에서는 보존.
  과거 하회 기록을 미래 고점·변동 폭으로 다시 판정하지 않는다. 예약 후 반등은 취소하지 않는다.
- 원래48봉 채널 청산·10% 영구 위험 중단·추가 청산 뒤 채널 리셋을 유지한다.
  계좌 고점이나 위험 중단을 초기화하지 않는다. 갭/비용으로 손실 상한 보장 불가.
- 동일 공개 BTC/KRW 시간봉,200봉 워밍업,22개 독립 계좌 각100만 원.
  평가36,384/40,896시간(88.97%). 결측 보간 없음, 계좌 내 분기 경계 상태 유지.
- 전액 다음 시가, 편도 수수료0.05%·슬리피지0.1%, 최소5천 원·수량1e-8.
  기본/슬리피지2배/비용2배/추가1시간 지연. 기존·현금·prior·45·후보440회.

## 다음 사전 명시 실험 47 — 손실 청산에만 채널 리셋 대기

후보 하나 `entry-stop-loss-reset`을46과 비교한다. 추적 거리·활성·청산선을 더 조정하지 않고
손실 이후 반복 진입 제한과 수익 보호 이후 재진입 제한을 구분한다.

- 46의 진입·초기 TR/손절·가변 추적/하향 금지·두 종가 확인을 그대로 유지한다.
- 추가 청산만 성립한 주문이 실제 매도되면 방금 끝난 매수/매도 체결로 순손익을 계산한다.
  `매도 체결가×수량−매도 수수료−매수 체결가×수량−매수 수수료`.
  체결가는 슬리피지 반영 가격이다. 원시 시가·미실현 손익·계좌 전체 손익으로 대신하지 않는다.
- 거래 순손익이 엄격하게 양수이면 채널 리셋 잠금을 걸지 않는다.0 또는 음수이면46과 동일.
  매도 시점에 이미 관찰된 체결 정보만 사용하며 이후 수익이나 원래 전략의 미래 청산은 보지 않는다.
- 잠금이 없으면 실제 매도 봉의 확정 종가부터 원래 독립 돌파를 다시 평가한다.
  자동 즉시 재매수는 없고, 새 신호·다음 시가·추가 지연·최소 주문 조건을 유지한다.
- 일반/동시 채널 청산은 기존처럼 잠금 없음. 위험 주문은 영구 중단 유지.
  매도 미체결이면 새 잠금 판단이나 상태 초기화 없음. 새 실제 매수의 고점·TR·청산선은 재설정.
- 이익을 확정한 직후 재진입하여 추세 말기에 반복 손실/비용이 커질 수 있다.
  손익0 임계값은 비용 포함 손실 여부의 구분이며 결과에 맞춰 양수 임계값을 탐색하지 않는다.
- 동일 자료·200봉 워밍업·22계좌·4조건·모든 사전 기준 유지.
  기존·현금·prior·46·후보440회, 기존/46 대조176개 전체 JSON 재현 요구.
- 47은 계획만 고정했으며 구현·실행·새 홀드아웃·실거래 승격은 하지 않았다.
