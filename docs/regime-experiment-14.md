# 실험 14: 장기 추세 입력 비교

## 실행 전 고정 계획

실거래·Config Server·계좌·DB는 변경하지 않는다. 수익성 개선을 위한 오프라인 탐색이며,
이미 관찰한 2022-01-01~2026-09-01 UTC의 가용 연속 블록을 재사용한다.
이번 결과를 새로운 홀드아웃 성과로 해석하지 않는다.

- 두 입력군: 기존 5채널 + 0채널 5개(`short-matched`), 기존 5채널 + 장기 지표 5개(`long`).
- 장기 지표: 24/72/168시간 로그 수익률, 48시간/168시간 이동평균 로그 비율, 24시간 수익률 표준편차.
- 공통 200시간 준비 구간, 32x10 입력, MLP 320-32-16-3, 시드 17/29/43.
- 같은 학습·검증 신호 시각/레이블을 해시로 비교한다. 모델 크기·초기 가중치·배치 순서도 같은 시드에서 일치한다.
- 기존 24시간 장세 목표, 7분기 학습/1분기 검증, 레이블 경계 제거, 학습 표본만의 정규화·클래스 가중치.
- 최대 100 epoch, patience 10, 가중치 없는 검증 교차 엔트로피 최저 모델 복원.
- 주 후보는 딥러닝 돌파 진입 필터. 확인 3회·체류 6시간, 진입 임계값 .55, 청산은 원래 돌파 전략 그대로.
- 기본 수수료 편도 0.05%·슬리피지 0.1%, 슬리피지 2배·전체 비용 2배·1시간 지연을 함께 평가한다.
- 10% 낙폭 중단, 연속 블록 안 원금 유지 및 분기 모델 교체, 결측 구간 사이 독립 원금 100만 원.
- 입력군 간 같은 평가 구간·돌파/현금 결과까지 일치해야 비교를 허용한다.
- 모든 시드/비용에서 기존 안정성 조건을 통과하고 장기 입력의 대조군 대비 블록별 수익 차이 중앙값이 양수여야 후속 채택 후보로 본다. 자동 실거래 승격은 없다.

장기 준비 구간 때문에 실험 12/13과 평가 시간이 달라질 수 있다. 이전 +2% 중앙값을 그대로
대조군으로 가져오지 않고 같은 구간의 원래 돌파를 재실행한다. 추가 입력이 0인 대조군은
파라미터 텐서 크기는 같지만 추가 입력의 정보량·유효 자유도는 다르다.
최근 8일은 이미 관찰했으므로 이번에는 새 검증처럼 재평가하지 않는다.

```bash
.venv/bin/python -m evergreen.research.experiments.regime_features \
  --source data/regime-08-2020-2026-public \
  --output outputs/regime-experiment-14
```

결과는 출력 디렉터리의 `summary.md`, `results.json`, `status.json`에 기록한다.
기존 연구 결과를 덮어쓰지 않는다. 최고 시드를 골라 성공으로 보고하지 않는다.

## 구현 검증

- Ruff 검사·포맷 검사, mypy 88개 파일 통과.
- 전체 테스트 280개 통과, 22개는 테스트용 MariaDB 미설정으로 제외. 커버리지 90.02%.
- 미래 봉을 추가해도 기존 시점 특성이 불변인지, 두 입력군의 시각·레이블이 일치하는지 검증했다.
- 작은 실제 모델 6개 학습부터 공통 백테스트·비교 보고서 생성까지 연결 테스트했다.
- 학습/검증 표본 해시 불일치는 비교 거절, 실패 시 완료 상태 대신 실패 기록 생성.
- 실험 12/13의 기존 체크포인트 114개를 새 로더로 모두 불러와 호환성을 확인했다.
- Spark 독립 소스 리뷰: 블로커 없음. 시간대 없는 평가 시각과 학습 경계 없는 체크포인트는
  누출 검증이 불가능하므로 기존처럼 거절한다. 이 제한을 호환성 명목으로 완화하지 않았다.

## 실제 결과

두 입력군 x 세 시드 x 19분기 = 114개 모델을 실제 학습했다. 모든 조합은 22개 연속 블록,
36,384시간(계획 40,896시간의 88.97%)에서 평가했다. 200시간 준비 구간 때문에 이전 실험보다
682시간 줄었다. 학습·검증 표본 해시, 같은 시드의 학습 설정, 평가 구간, 공통 돌파/현금 결과가
입력군 간 모두 일치했다. 실행 실패 기록은 없으며 사전 탐색 통과 조건은 미달이다.

기본 비용의 주 후보(돌파 진입 필터) 결과:

| 입력 | 시드 | 블록 수익 중앙값 | 거래 블록/22 | 청산 | 최악 낙폭 | 돌파 대비 블록별 차이 중앙값 |
|---|---:|---:|---:|---:|---:|---:|
| 기존 입력 대조군 | 17 | 0.00% | 3 | 8 | 8.68% | -1.03%p |
| 기존 입력 대조군 | 29 | 0.00% | 5 | 10 | 6.73% | -1.98%p |
| 기존 입력 대조군 | 43 | 0.00% | 5 | 9 | 6.73% | -0.36%p |
| 장기 입력 | 17 | 0.00% | 8 | 15 | 9.15% | -3.00%p |
| 장기 입력 | 29 | 0.00% | 9 | 15 | 10.38% | -2.35%p |
| 장기 입력 | 43 | 0.00% | 12 | 20 | 9.56% | -3.51%p |

같은 구간의 원래 돌파 전략 중앙값은 +2.00%였다. 이는 구간별 독립 원금의 분포이며 전체 기간
누적 수익이나 앞으로의 예상 수익이 아니다. 장기 입력도 미거래 구간을 포함한 중앙값이 0%이며,
기본 비용에서 양수 구간은 세 시드 모두 3/22개뿐이다. 장기 입력과 대조군의 직접 비교에서도
개선/악화 구간 수는 각각 2/6, 3/7, 4/10으로 악화 쪽이 많았다.

장기 입력의 전체 비용 2배 조건에서 최악 낙폭은 시드별 9.55%/11.05%/10.37%,
1시간 지연에서는 8.72%/11.33%/10.74%였다. 10% 중단 규칙은 체결 지연·갭·비용 때문에
실제 손실을 정확히 10%로 제한하는 보장이 아니다.

분기별 혼동행렬을 합쳐 계산한 macro F1도 개선되지 않았다:

| 시드 | 기존 입력 대조군 | 장기 입력 |
|---|---:|---:|
| 17 | 0.3441 | 0.3332 |
| 29 | 0.3470 | 0.3444 |
| 43 | 0.3474 | 0.3435 |

실제 학습 종료 epoch는 대조군 11~29, 장기 입력 11~32였고, 복원한 최적 epoch 중앙값은
각각 6과 4였다. 단순히 epoch 수를 늘리는 방식으로 해결됐다고 볼 수 없다.

판정: **이번 고정 실험 조건에서는 장기 지표를 추가한 모델을 채택하지 않는다.** 관찰한 블록·
세 시드·모델 구조·지정 비용 조건에서 거래는 늘었지만 분류와 수익성이 좋아지지 않았다.
다른 입력이나 모델까지 모두 무효라는 뜻도, 원래 돌파가 보편적으로 최적이라는 증명도 아니다.
운영 전략·설정·계좌는 변경하지 않았다. 최종 Spark 결과 해석 리뷰의 범위 한정 의견을 반영했다.
다음 연구 가설은 장세 전체 분류보다 **실제 돌파 진입 후보가 비용 차감 후 유리한 거래인지**를
직접 예측하는 것이다. 기존 메타 레이블 연구를 먼저 검토해 중복을 피하고, 거래 종료 시점까지
학습 경계를 제거하며 동일 거래 청산 규칙·시드·비용으로 비교해야 한다. 아직 실행한 결과는 아니다.

전체 비용별 결과는 `outputs/regime-experiment-14/summary.md`, 원자료·체크포인트·예측·체결 내역은
동일 디렉터리 아래에 보존했다. 새 실거래 전략의 유효성은 입증되지 않았다.
