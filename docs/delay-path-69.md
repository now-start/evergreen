# 실험69 — 기본/추가1시간의 신호·중단 경로

## 실행 전 계약

실험68의 후속 계획을 따른다. 기존67의 원 돌파·50·57·67,22계좌×2조건176개
결과를 고정한다. 새 전략·임계값·모델 학습·승격은 없다.

매수/매도 방향·원래 신호 시각·사유로 체결 순서를 비교하고,
공통 신호 구간의 실제 체결 시간차와 최초 신호 경로 불일치를 따로 기록한다.
각 계좌의 매수 거절 내역과 중단 변화도 저장한다. 경계 정산은 신호 주문과 구분한다.
중단 여부가 달라진 모든 전략·계좌 쌍은 기본·지연 모두 캐시 봉으로 관찰 재실행하고
전체 JSON 일치를 요구한다. 기존 관찰기의 최초 낙폭 초과·체결 비용·대기 주문 맥락을 쓴다.

전략별 지연−기본 손익 변화와57−원 돌파 비교 차이의 변화를 모두 합산한다.
주문·수량·중단이 달라지는 실행 경로의 진단이지 고정 체결 가격 효과의 인과 추정이 아니다.
자료는 이미 관측한 탐색 구간이며 미관측 검증이 아니다.10% 한도와 기존 게이트를
바꾸지 않으며 실거래·설정·DB·버전·배포·커밋·푸시는 변경하지 않는다.
테스트·해시 검증을 수행하고 독립 리뷰는 사용자 지시로 생략한다.

```bash
.venv/bin/python -m evergreen.research.experiments.delay_path --reference outputs/breakout-entry-cadence-67 --output outputs/delay-path-69
```

## 결과 — 지연이 손익을 단조롭게 악화시키지 않는다

출력은 `outputs/delay-path-69`다.176개 결과·원래 입력 해시·손익·비용·경계를
검증했다. 중단 여부가 달라진5쌍의 기본/지연10개 결과를 모두 관찰 재현했다.
참조256개·소스74개 해시, 원본176개 JSON의 정규화 전후 일치, 신호 공통 구간과
손익 합계도 별도 계산으로 확인했다. 기존 전략·위험 정책은 변경하지 않았다.

| 전략 | 지연−기본 합산 손익 | 신호 경로가 달라진 계좌 | 중단 계좌 기본→지연 | 매수 거절 기본→지연 |
|---|---:|---:|---:|---:|
| 원 돌파 | +421,784원 | 4/22 | 4→1 | 0→0 |
| 50 | -52,102원 | 15/22 | 0→1 | 18→2 |
| 57 | +74,811원 | 15/22 | 0→0 | 18→16 |
| 67 | +147,273원 | 9/22 | 1→0 | 0→3 |

57의 절대 손익은 지연으로 늘었지만, 원 돌파의 증가가 더 커서 상대 변화는
-346,973.553801원이다. 이를57이 지연만으로34.7만원을 잃었다고 표현하면 틀린다.
계좌011의 상대 변화 -357,068.646497원과 나머지21개 +10,095.092695원의 합이다.
모든 금액은22개 독립100만원 시작 계좌의 손익 합이며 단일 계좌 누적 수익이 아니다.
거절 기록에는 체결 시도 시각이 있고 원 신호 시각은 없으므로 거절을 정확한 신호와
임의로 연결하지 않았다. 결과 JSON에 모든 매수 거절 기록을 그대로 보존했다.

### 011에서 비교 우위가 크게 뒤집힌 이유

원 돌파의 첫 매수 신호는2024-01-11 15 UTC로 같다. 기본은66,084,000원,
지연은16시64,311,000원 시가를 기준으로 매수했다. 첫 전략 매도 신호도
01-12 22시로 같지만 기본59,986,000원,지연23시59,282,000원에 체결된다.
가격·수량·손실 누적이 달라진 상태에서01-28의 두 번째 포지션으로 들어간다.

기본은01-28 08시58,433,000원 종가에서 평가금899,400.324389원이 돼 최초
원금100만원의10% 한도를 넘었다. 이후 위험 매도로898,051.673862원이 되고 중단한다.
지연은 같은 정책에서 최대낙폭9.8992%로 한도를 넘지 않아 이후 거래를 계속했고
최종1,279,272.002548원이 됐다. 원 돌파011의 지연−기본 손익은+381,220.328686원이다.

57은 이 계좌에서 두 조건 모두 중단하지 않았고 최종1,203,434.323179원과
1,227,586.005369원이다. 원 돌파의 한도 근처 경로 변화가 비교 결과에 큰 영향을
준 것은 확인됐지만, 그 뒤 수량·주문·중단 정책이 함께 달라져 이를 초기 매수 가격의
단독 인과 효과로 추정하지 않는다. 실거래 지연을 늘리는 권고도 아니다.

## 판단과 후속70 사전 계획

57의 기존 네 조건 전체 통과 실패는 유지한다. 원 돌파의 위험 한도 경계 민감도가
비교 우위 변화의 큰 원인이지만, 그 한도나 실패 계좌를 없애서 후보를 승격하지 않는다.
동일 기간에서 임계값을 더 검색하기보다, 고정57의 다른 역사 구간 검증으로 진행한다.

최근 구간을 새 검증으로 쓰기 전에 저장 자료를 확인했다.2026-09-01~09-09는
이미 `data/regime-12-september`와 실험12에서 평가됐다. 이를 새 미관측 구간이라고
재사용하지 않는다. 현재 연구 데이터 manifest에서2018~2019 평가 자료는 발견되지
않았고, 기존2020자료의 준비 구간이2019-12-24부터 일부 겹치는 정도다.

- 70의 고정 평가 범위는 UTC2018-01-01~2020-01-01이다. 정책57 하나를 후보로 고정하고
  원 돌파·현금·매수보유를 대조로 둔다. 모든 지표·조건은 수집 결과를 보기 전에 고정한다.
- 공개BTC/KRW 시간봉만 수집한다. 실제 계좌/API거래키·설정 서버·DB에 접근하지 않는다.
  준비200시간을 포함해 수집하며 원본 응답·요청·해시를 보존한다. 과거 자료의 제공 가능성은
  수집으로 확인한다. 없는 봉을 만들거나 요청 실패를 무거래 시간으로 간주하지 않는다.
- 충돌·미완성·누락을 검증한다. 완전 연속이면 한 계좌로2018~2019를 이어서 평가한다.
  누락이 있으면 관측된 연속 블록마다 준비200봉 이후에 남은 모든 시간만 독립 계좌로
  평가하고, 평가 시간/전체17,520시간과 누락을 공개한다. 수익에 따라 블록을 고르지 않는다.
- 각 계좌는100만원, 기존57의168시간 돌파·24시간 추세 맥락·진입 예산·버퍼를 그대로
  사용한다. 분할·레버리지·4시간 제한·장기 평균 필터를 추가하지 않는다.
- 기본/슬리피지2배/비용전체2배/추가1시간 조건과 기존 수익·위험 게이트를 그대로 사용한다.
  분모는 실제 유효 계좌 수이며 수익 계좌는 과반, 대응 중앙값>0, 최대낙폭<=10%, 중단0,
  기본 자연청산>=10회다. 검증 대상 전체가 누락된 경우 실패이며 빈 결과를 통과시키지 않는다.
- 이는 새로 평가하는 **더 오래된 역사 구간의 일반화 점검**이다. 시간순 전진 검증이나
  다중 탐색을 보정한 통계적 미관측 홀드아웃으로 부르지 않는다. 일부 준비봉은 이미 봤다.
  거래 비용은 기존의 동일한 가정이며 당시 실거래 수수료·유동성을 재구성했다고 주장하지 않는다.
- 70이 통과해도 현재2022~2026의 지연 실패는 없어지지 않는다. 조건을 재선택하거나
  운영 승격하지 않고, 연속 평가·기본 동작·해시·손익·지연 원 신호를 테스트한다.
  가능하면 기존67 대조 중 원 돌파·57의176개 JSON 재현도 확인한다.
