# 실험 13: 장세 목표 기간 72시간

실험 12의 시드 결과와 최근 보조 평가 수익을 확인하기 전에 고정한 후속 가설이다.
24시간 상승 판단보다 72시간 장세 판단이 168시간 고점 돌파의 진입 필터에 더 적합한지 검증한다.

- 실험 12의 시드 17·29·43, 모델·특징·학습/검증 기간·조기 종료·가중 손실·정책·비용 조건을 유지한다.
- 목표 수익 기간만 24시간에서 72시간으로 바꾼다. 변동성 임계값 공식은 동일하게
  `max(0.003, 과거24시간 수익 표준편차 * sqrt(예측기간))`를 사용한다.
- 미래 레이블 사용 가능 시각도 72시간 후로 바뀐다. 학습·검증 경계에서 72시간 미래 레이블을 제거한다.
- 예측 점수 임계값은 0.55 그대로다. 72시간 결과를 보고 임계값을 바꾸지 않는다.
- 모든 시드·비용 결과를 공개한다. 시드마다 유리한 목표 기간을 골라 붙이지 않는다.
- 두 목표의 레이블이 다르므로 분류 F1을 직접적인 동일 과제 개선율로 해석하지 않는다.
  동일 평가 구간에서의 비용 차감 수익·낙폭·거래 수와 기존 돌파 대비 차이가 주 비교 기준이다.
- 최근 9월 보조 평가에서는 7월 분기 모델을 고정한다. 최근 가격·수익을 모델 선택에 사용하지 않는다.
- 실험 12와 동일한 탐색 안정성 조건이며 실거래 승격은 하지 않는다.

```bash
uv run python -m evergreen.research.experiments.regime_stability \
  --source data/regime-08-2020-2026-public --recent data/regime-12-september \
  --horizon 72 --output outputs/regime-experiment-13
```

과거 관찰 구간의 재탐색과 최근 8일의 짧은 사후 평가를 구분해 보고한다.
