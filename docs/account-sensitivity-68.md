# 실험68 — 한 계좌씩 제외하는 고정 민감도 진단

## 실행 전 계약

실험67 문서에서 사전 명시한 진단이다. 새 전략, 임계값 검색, 모델 학습은 없다.
이미 관측한22개 계좌의 원 돌파·50·57·67, 네 조건352개 저장 결과를 읽고
원 결과 해시·손익·비용·계좌 경계·요약·게이트가 일치하는지 먼저 확인한다.

50/57/67 각각 원 돌파 대비, 그리고57 대비67의 개선 방향(57−67)을 비교한다.
전체 대응 차이와 계좌 한 개씩 제외하는22개 결과를 모두 기록한다.
최소/최대 대응 수익률 차이 중앙값·합산 손익 차이, 부호 변화, 영향 계좌,
계좌 길이·거래 수·손익 기여를 보고한다. 대응 중앙값은 개별 차이를 먼저 구한다.

제외 결과로 공식 게이트를 재계산하거나 불리한 계좌를 없애지 않는다.
통계적 독립·동일 분포를 가정하지 않으며 신뢰구간·유의확률·미관측 성능이 아니다.
57의 추가1시간 게이트 실패와 실거래·설정·DB·버전·배포 무변경을 유지한다.
테스트는 손계산 중앙값·빠짐없는 제외·시간 경계·비용·누락·변조 실패 처리를 포함한다.
독립 리뷰는 사용자 지시로 생략한다.

```bash
.venv/bin/python -m evergreen.research.experiments.account_sensitivity --reference outputs/breakout-entry-cadence-67 --output outputs/account-sensitivity-68
```

## 결과 — 중앙값 개선과 합산 손익의 안정성은 다르다

최종 검증 출력은 `outputs/account-sensitivity-68-verified`다. 최초 실행 이후 타입 표기와
변수명 충돌만 고치고 새 경로로 재생성했으며, 두 실행의 `results.json`은 완전히 같다.
최초 출력도 보존했다. 재실행 시 위 명령의 출력 경로를 새 경로로 지정해야 한다.

352개 결과의 원 해시·거래 손익·체결 비용·경계·요약·기존 게이트를 검증했다.
16개 비교(네 조건×네 비교)의 전체22계좌 및 한 계좌씩 제외한352개 진단을 기록했다.
별도 계산으로 모든 제외 인덱스·중앙값·손익 차이를 대조했다.
참조 파일357개와 최종 소스73개 해시도 일치했다. 새로운 학습이나 매매는 없다.

## 후속69 사전 계획 — 지연에 따른 체결·중단 경로 진단

68은 새 후보가 아니며57의 추가 지연 실패를 그대로 유지한다.
67을 폐기하고 임계값을 다시 검색하기 전에, 지연 조건에서 왜 비교 우위가 사라지는지
구체적인 실행 경로를 확인한다.

추가 확인에서57−원 돌파의 합산 손익 차이는 기본→지연에서 -346,974원 악화됐다.
011만의 변화는 -357,069원이며 나머지21개 변화 합은 +10,095원이다.
011의 원 돌파는 기본 조건에서10.1948% 낙폭으로 중단·최종 -101,948원이지만,
지연 조건에서는9.8992%로 중단하지 않고 +279,272원이 된다.
57은 두 조건 모두 중단하지 않고 +203,434/+227,586원이다.
이는 저장 결과에서 확인한 사실이며, 최초 한도 초과의 원인은 아직 관찰 재현 전이다.

- 69는67의 원 돌파·50·57·67에서 기본/추가1시간의176개 결과를 고정한다.
  원자료·원금·10% 한도·매매 조건을 바꾸지 않는다. 수익·위험 게이트를 다시 정의하지 않는다.
- 계좌별로 각 전략의 지연−기본 손익 차이를 계산하고,
  `(57지연−원돌파지연)−(57기본−원돌파기본)`의 정확한 합계와 기여를 보고한다.
- 매수/매도 방향·원래 신호 시각·사유로 체결 순서를 비교한다. 모든 체결 시각이
  단순히1시간 이동한 것을 새 신호로 오인하지 않고, 최초 신호 경로 불일치와 매수 거절,
  중단 상태 변화 계좌를 빠짐없이 나열한다.
- 중단 여부가 달라진 모든 전략·계좌 쌍은 캐시 봉으로 두 조건을 관찰 재실행한다.
  각 전체 JSON이 원본과 같아야 하며 기존 `observe`/`first_breach`로 최초 초과를
  보유 가격 변화·체결 비용·주문 대기 맥락으로 구분한다. 중단하지 않은 짝도 함께 검증한다.
- 금액 합계와 신호 경로 차이는 진단이지 인과적 가격 효과 추정치가 아니다.
  다른 주문·수량·중단 상태가 함께 바뀌는 것을 고정 체결 가격 효과로 부르지 않는다.
- 신호 시각과 체결 시각 구분, 동률/누락/변조, 손익 차이 합계, 원본 재현 테스트를 둔다.
  새로운 신호 모델·임계값·위상 검색과 운영 변경은 하지 않는다.
