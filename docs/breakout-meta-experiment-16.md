# 실험 16: 거래 사건 검증 기간 확대

## 실행 전 고정 계획

실험 15의 거래 성과를 보고 임계값을 조정하는 실험이 아니다. 먼저 확인한 표본 현황은
완결 사건 723개·비중첩 사건 115개, 학습 적격 분기 7/19개였다. 부족한 검증 사건 때문에
많은 분기가 현금 대기로 남으므로, **같은 총 8분기 자료창을 학습 6분기·검증 2분기로
재배분하면 검증 표본 부족을 줄일 수 있는가**를 확인한다.

- 변경: 학습 7/검증 1분기 → 학습 6/검증 2분기. 검증만 늘리는 효과와 학습 축소 효과가 함께 있다.
- 유지: 원자료·대상 기간·레이블·비용·보유 제한 없는 청산·32x5 입력·MLP/CNN·시드 17/29/43.
- 최소 사건 수, 비중첩 사건 수, 두 클래스 조건, 임계값 .50, 조기 종료, 위험 규칙 모두 유지한다.
- 부족한 분기는 계속 현금 대기하고 평가에 포함한다. 좋은 분기만 골라 보고하지 않는다.
- 같은 원래 돌파·현금·학습 양수 비율의 상수 예측을 비교한다.
- 실험 15와 같은 사전 채택 조건을 모든 시드·비용에서 확인한다. 자동 실거래 승격 없음.
- 이미 관찰한 과거 자료이며 미래 수익성이나 새 홀드아웃 검증을 주장하지 않는다.
- 운영 전략·Config Server·계좌·DB·배포를 변경하지 않는다.

.venv/bin/python -m evergreen.research.experiments.breakout_meta \
