# 실험 32 — 진입 전 변동 폭을 반영한 돌파 실패 청산

## 사전 계획

실험31의 실패 청산57건 중32건은 돌파선 이탈 폭이 진입 전24봉 평균 True Range 이하였다.
두 시간 확인 후에도 일상적인 가격 변동에 반응하는지 검증하기 위해 가격 여유를 둔다.
이 진단은 실제 경로의 사후 분석이며, 이 거래들을 유지하면 수익이라는 뜻은 아니다.

- 후보 하나 `failed-breakout-tr24`. 실제 매수의 원래 신호 봉 이전168봉 최고가에서
  **신호 봉 이전24봉 True Range 단순 평균 하나**를 뺀 가격을 고정 청산 기준으로 둔다.
  각 True Range는 `max(고가-저가, |고가-이전종가|, |저가-이전종가|)`이다.
  첫24봉의 이전종가 계산에 필요한25번째 과거 봉도 사용한다. 신호 봉은 제외한다.
- 실제 매수마다 기준을 다시 잡고 이후 변동성으로 이동시키지 않는다. 1시간 추가 체결
  지연에서도 원래 신호 시각 기준이다. 평균이0이면 기존 돌파선과 같은 기준을 사용한다.
- 보유 중 확정 종가가 기준보다 낮으면 다음 시가 청산, 같은 값이면 청산하지 않는다.
  2시간 확인·재진입 대기·위험 예산 필터는 결합하지 않는다. 원래48봉 저점 청산과
  10% 영구 위험 중단, 기존 수수료·슬리피지 모형·수량 단위·최소 주문 조건은 그대로다.
- 기간24·배수1을 고정한다. 0.5/1/2배 탐색이나 결과에 따른 재선택은 하지 않는다.
  기존 돌파·현금·prior·실험30의1시간 청산·실험31의2시간 청산을 대조로 유지한다.
  기존·1시간·2시간 대조의264개 전체 JSON이 실험31과 같아야 완료 처리한다.
- 같은 원자료SHA·22개 연속 구간·200시간 워밍업·36,384/40,896시간(88.97%).
  각 구간 독립 원금100만 원, 구간 내부 분기 경계는 상태 유지, 결측 보간 없음.
  구간별 중앙값·독립 손익 합계로 보고하고 단일 누적·연환산 수익률로 표현하지 않는다.
- 기본·슬리피지2배·수수료와 슬리피지2배·추가1시간지연 모두 기존 대비 대응 수익률
  차이 중앙값>0, 수익 구간 과반, 최대 낙폭≤10%, 위험 중단 없음, 기본 자연 청산10회
  이상이 필요하다. 10% 중단은 지연·갭·비용을 포함한 실제 손실 상한 보장이 아니다.
- 이미 반복 관찰한 과거 자료의 탐색이며 미관측 홀드아웃이나 딥러닝 학습이 아니다.
  실거래·Config Server·DB·배포·버전·커밋·푸시는 변경하지 않는다.

### 실패 원인

- 완결 거래는2시간 청산105→95건으로 줄었으나 원래72건보다 많다.
  수수료98,711원·모형상 슬리피지 비용197,424원도 기존75,691원·151,383원보다 높다.
- `block-011`의 개선289,652원을 제외한 나머지21구간 합산 차이는 -275,871원이다.
  기본 합계의 작은 개선이 특정 구간에 의존하는 문제가 반복됐다.
- `block-017`에서는 기존 +107,414원 대비 후보 -11,728원이다. 조기 청산 뒤 재진입에서
  손실이 추가되며2025-09-10 위험 중단이 발생했고, 이후 기존 전략의 수익 거래에
  참여하지 못했다. 계좌 고점과 위험 중단 상태를 유지한 경로 차이이며, 개별 거래의
  손실이 작아졌다고 계좌 전체가 좋아지는 것은 아니다. 날짜는 UTC다.
- 실험30~32의 즉시·2시간·변동 폭 조정은 모두 기존 전략보다 일관된 개선을 보이지
  못했다. 청산 여유를 다시 임의 조정하는 대신 다음에는 원래 청산을 복원하고 진입을 검토한다.

### 다음 사전 명시 가설 — 진입 과열 제한

원래72개 기본 거래를 진입 신호의 `종가-이전168봉 최고가`가 진입 전24봉 평균
True Range를 초과하는지로 사후 분류했다. 이하34거래는17개 수익·합산+718,277원,
초과38거래는16개 수익·합산+471,243원이었다. 두 집단 모두 양수이며, 초과 거래를
제외하면 좋은16거래도 잃는다. 이 분해는 필터 적용 후 연속 계좌의 수익을 계산한 것이
아니므로 단순 합계만으로 우월성을 주장하지 않는다.

실험33은 `종가 > 기존 돌파선 ×1.001`을 유지하면서, 돌파선 위 이격이 신호 전24봉
평균 True Range **이하**인 경우만 진입하도록 단일 상한을 추가한다. 같은 값은 허용한다.
종가가 돌파선에서 과도하게 멀어진 진입을 제한하는 가설이며, 해당 신호 봉은 변동 폭
계산에서 제외한다. 청산은 원래48시간 저점·10% 위험 중단만 사용하고 실험30~32의
조기 청산은 결합하지 않는다. 24시간·1배를 고정하며 다른 배수 탐색은 하지 않는다.
데이터·계좌 상태·비용·지연·평가 기준은 동일하다. 아직 구현·실행하지 않은 탐색 가설이고,
미관측 검증이나 실거래 승격이 아니다.
