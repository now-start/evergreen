# 실험 09–11: 장세 예측과 매매 정책 분리

## 실행 전 고정 조건

목표는 08b의 보합 예측 쏠림과 평균회귀 손실을 분리하는 것이다. 운영 전략은 변경하지 않는다.
이미 관찰한 과거 자료를 재사용하므로 새로운 홀드아웃 검증이나 수익 보장이 아니다.

- 데이터: `data/regime-08-2020-2026-public`, 원본 해시 재검증.
- 분할: 08b와 동일한 이전 7분기 학습, 직전 1분기 검증, 다음 분기 평가.
- 특징·24시간 레이블·정규화·MLP·seed 17·최대 100 epoch·patience 10 유지.
- 기존 학습과 균형 학습을 모두 재실행. 균형 가중치는 학습 표본만으로 `N/(3*N_class)` 계산.
- **학습 손실만 변경**한다. 두 학습 모두 비가중 검증 cross entropy 최저 epoch 복원.
  균형 검증 손실이나 macro F1로 epoch를 선택하는 실험은 이번 범위가 아니다.
- 확률 점수 0.55, 3시간 확인, 6시간 최소 장세 유지 고정. 임계값 탐색 없음.
- 독립 연속 블록별 원금 100만 원, 분기 경계의 잔고·고점·중단 상태 유지.
- 결측은 보간하지 않으며 08b의 같은 적격 블록을 평가한다.
- 편도 수수료 0.05%, 슬리피지 0.1%. 슬리피지 두 배·전체 비용 두 배·추가 1시간 지연도 비교.
- 10% 낙폭 중단은 손실 보장이 아니며 실행 가격에 따라 초과 가능하다.

## 고정 비교군과 후보

1. 현금, 기존 돌파, 기존 장세 전환: 동일 데이터·비용의 대조군.
2. 항상 평균회귀: 모델 없이 평균회귀 자체의 성과 측정.
3. 항상 보합 더미: 모델 대신 보합만 예측하고 같은 확인 규칙을 적용.
4. **09 보합 신규 매수 금지**: 상승 돌파만 진입. 보합 전환 시 기존 포지션 강제 청산 없음.
   기존 포지션은 돌파 매도·하락 장세 청산·위험 중단을 유지한다.
5. **10 균형 학습**: 같은 정책에서 기존 학습과 비교해 가중 학습의 효과 분리.
6. **11 돌파 진입 필터**: 상승 확인 시 돌파 매수만 허용. 이후 장세가 하락해도 모델로 청산하지 않고
   기존 돌파 매도와 위험 중단만 적용한다.

성과: 블록별 비용 차감 수익·낙폭·청산 횟수·노출·수수료·슬리피지, 분류별 정밀도/재현율/혼동 행렬.
보고서의 수익 중앙값은 누적 수익률이 아니다. 무거래 0%는 성공이 아니다.
기존 돌파보다 개선되어도 단일 시드 탐색에 불과하므로 자동 승격하지 않는다.

uv run python -m evergreen.research.experiments.regime_followup \
  --source data/regime-08-2020-2026-public \
  --output outputs/regime-experiment-09-11

출력 디렉터리는 새 경로여야 한다. 각 모델의 체크포인트·epoch 손실·분기 예측·블록 주문 및 원금 곡선,
`comparisons.json`, 한글 `summary.md`를 보존한다. 계좌 API·실제 주문·Config Server·DB는 사용하지 않는다.

기존 방식 재학습의 연속 블록 결과와 분류 핵심 지표는 이전 08b 검증 결과와 일치했다.

### 해석과 결정

- 평균회귀 대조군 자체의 손실이 크다. 현재 형태를 보합장의 기본 전략으로 채택할 근거가 없다.
- 기존 MLP의 두 보수적 정책은 실제 노출·수수료도 모두 0이다. 손실 회피가 아닌 **무거래** 결과다.
- 균형 MLP의 돌파 진입 필터는 22개 중 3개 블록에서만 거래했다. 해당 블록의 수익은
  +20.77%, +1.92%, +5.99%였지만, 나머지 19개는 무거래다. 거래한 블록만 골라 성공을 주장하지 않는다.
- 전체 비용 두 배에서도 이 필터의 양수 블록은 3/22, 청산 7회, 최악 낙폭 8.97%다.
  후보로 남길 수는 있지만 표본이 적어 기존 돌파보다 우월하다고 판정하지 않는다.
- 균형 MLP 장세 전환은 낙폭 중단 2개 블록이 있고 최악 낙폭 12.58%로 위험 기준을 충족하지 못했다.
- **실거래 승격 없음.** 다음에는 사전 고정된 다른 시드와 새로운 기간으로 재현성을 확인한다.
  관찰한 결과에 맞춰 이번 임계값을 낮추거나 과거 구간을 재선택하지 않는다.

검증: Ruff/포맷/mypy 통과, 전체 271개 테스트 통과, 22개 MariaDB 통합 테스트는 일회용 DB 미설정으로 제외.
총 커버리지 90.20%. 기존 전략의 결정론적 결과 해시도 유지됐다.

가중 손실의 클래스별 가중치와 평균 계산은 [PyTorch CrossEntropyLoss 문서](https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html)를 확인했다.
