# 실험 71 — 사용자 요청에 따른 청산 여유 완화

## 실행 전 고정한 계약

실험70의 최대 TR 후속 계획 대신 사용자 요청의 청산 완화 비교를 우선한다.
낙폭 평가 기준만 사후 변경하지 않고 실제 계좌 중단·진입 위험 예산·선제 청산선을
변경해 전체 거래 경로를 다시 계산한다. 운영 설정은 변경하지 않는다.

| 정책 | 계좌 낙폭 한도 | 초기/추적 손절 TR 배수 | 저점 청산 채널 |
|---|---:|---:|---:|
| original | 10% | 3 | 48시간 |
| risk15 | 15% | 3 | 48시간 |
| risk20 | 20% | 3 | 48시간 |
| wide15 | 15% | 4.5 | 72시간 |
| wide20 | 20% | 6 | 96시간 |

고정 후보는 원래 돌파, 28 윗꼬리 필터, 51 긴 추세 청산, 57 선제 청산,
23 겹침 조정 MLP 3시드 점수 평균 필터다. 실험별 모든 파생 전략을 재학습하는 요청으로
확장하지 않고, 직전 비교 대상 네 후보와 원래 돌파를 모든 고정 조건에서 재평가한다.

- 168시간 돌파×1.001·윗꼬리25%·MLP 점수>0.50·추세24/168시간은 유지한다.
- 51/57의 손절 TR 배수와 수익 추적 활성화 거리를 함께 늘린다. 청산선은 하향하지 않는다.
- 손절 연속2봉, 청산 의도 유지, 다음 시가 체결, 추가1시간 스트레스는 유지한다.
- 57의 예상 가격 여유 `(1+추가 지연)×평균 TR24`는 그대로다. 이 배수를 키우면
  오히려 빨리 팔기 때문이다. 선제 청산의 자산 기준만 계좌 고점의85%/80%로 내려간다.
- 51/57의 진입 예산 역시 같은 새 손절선·낙폭 한도로 평가한다. 매수 신호 공식은
  유지하지만 위험 예산 거절과 실제 진입 경로는 달라질 수 있다.
- 51/57의 재진입 초기화 채널은48시간을 유지한다. 청산 채널과 구분한다.
- 동결 MLP는 원래48시간 청산 레이블로 학습됐다. 청산 변경에 맞춰 재학습하거나
  이후 성과로 좋은 시드만 고르지 않는다. 목적 불일치 가능성을 결과의 한계로 기록한다.
- 2022~2026년 기존22계좌·36,384시간·200봉 준비를 동일하게 사용한다.
  MLP 원래 예측 해시/3시드 평균을 확인하고 기존5전략×22×4=440개 전체 결과를 재현한다.
- 2018~2019년 실험70의13계좌·14,889시간도 규칙4전략으로 평가한다.
  2022년 이후 학습 모델을 과거에 적용하지 않으며 MLP 결과를0으로 대체하지 않는다.
- 총3,240개 결과(최근22×5전략×5정책×4조건 + 과거13×4×5×4)를 실행한다.
  기본·슬리피지2배·수수료와 슬리피지2배·추가1시간 지연. 모든 체결 비용 포함.
- 원금은 계좌마다100만원. 합산 손익은 단일 계좌 누적/연환산 수익률이 아니다.
  결측을 연결·보간하거나 분기 경계에서 계좌를 초기화하지 않는다.

## 판정과 검증

정책별 기존 돌파, 각 전략의 original 정책에 모두 대응 비교한다. 최근/과거 구간을
별도 보고하며 합산으로 취약 구간을 숨기지 않는다. 주 순위는 네 조건 중 최저 합산
순손익, 보조는 기본 손익·수익률 중앙값·양수 계좌·최대낙폭·중단·비용·이익 집중도다.
이 순위는 이번 사전 고정된 탐색 지표이며 예전 실험의 성공 기준을 바꾸지 않는다.

후보 개선 게이트는 네 조건 모두 두 대조 대비 대응 차이 중앙값>0·양수 계좌 과반·
해당 정책의 낙폭 이내·중단0·기본 자연 청산10회 이상이다. 과거 규칙 전략도 같은
조건으로 별도 판정한다. 최선 점수와 게이트 통과를 구분하고 새 홀드아웃이라 부르지 않는다.

기본 설정 전체 JSON 재현, 낙폭 경계·진입 예산·손절 배수·채널 길이·예약 지연·
미래 봉 제외·모델 예측 범위/해시 실패·손익 합 검증을 테스트하고 전체 pytest를 실행한다.
실거래·Config Server·DB·배포·버전·커밋·푸시 변경 없음. 독립 리뷰는 사용자 요청으로 생략한다.

## 결과 — 더 늦은 청산은 일부 규칙 전략에 유효, 전체 개선 게이트는 미달

3,240개 조합 완료. 기존 전체 결과544개(최근440 + 과거 원 돌파/57의104)가
JSON 전체 일치했다. 원래 정책을 보존하면서 실제 주문·중단·후속 거래 경로를 재계산했다.
최근22계좌36,384시간, 과거13계좌14,889시간이다. 계획 시간 대비 각각88.97%,
84.98%이며 결측을 보간하지 않았다. 과거 MLP는 평가 불가로 제외했으며 현금0%로
치환하지 않았다. 모든 후보는 이미 본 자료에서의 탐색이고 전체 게이트 통과자는 없다.

### 딥러닝 복합은 청산을 더 늦춰도 개선되지 않았다

23의 최근 기본 합산 손익은 original1,438,763원 → risk15/20의1,434,515원 →
wide15의1,372,023원 → wide20의1,254,139원이다. wide20은 모든 비용 조건에서
원래23보다 순이익이 줄었고 네 조건 최대낙폭은10.9501% →18.6286%로 증가했다.
MLP에 원래48시간 청산 레이블로 학습된 점수를 그대로 사용했으므로, 이것은
동결 진입 필터의 청산 민감도이지 새로운 청산 목표로 재학습한 모델의 성과가 아니다.

## 해석과 다음 단계

- 이번 최근 구간 수익 순위:51 wide20. 과거까지 위험 중단 없이 유지한 수익 후보:57 wide20.
- 두 후보 모두 수익 개선이 모든 계좌에 고르지 않고 지연/과거 게이트에 약점이 남는다.
- 연구 후보로 보존하되 운영 교체하지 않는다. 사후에 지연·무거래 계좌를 빼거나
  수익률 중앙값 조건을 낮춰 통과로 만들지 않는다.
- 추가 실험을 한다면 같은 시점의 진입을 고정한 청산 비교 또는 MLP의 변경된
  청산 목표에 맞춘 시간순 재학습을 따로 계획해야 한다. 이번에는 수행하지 않았다.

## 재현 및 검증

```sh
.venv/bin/python -m evergreen.research.experiments.relaxed_exits \
  --output outputs/relaxed-exits-71-verified
```

출력은 기존 경로에 덮어쓰지 않는다. 최초 실행의 디렉터리 생성 누락 오류는
`outputs/relaxed-exits-71/failure.json`에 남겼고, 생성 경로를 보완한 뒤 새 경로에서
전체 실행했다. 성공 경로와 실패 경로를 섞지 않았다.

동결 MLP36,406시점 점수를 원래3시드 평균과 대사하고 분기 경계에서는 새 모델이
소유하도록 기존 실행기의 규칙을 재현했다. 누락·해시 손상·평균 불일치·미래 레이블은
실패 처리한다. 실제 데이터를 사용한 기본 결과544개 전체 JSON 재현과 별도로,
3,240개 저장 결과의 체결 손익·자산·비용·보고 합계·낙폭·중단 수를 다시 계산해 일치했다.
산출물3,245개·입력826개·소스76개 SHA256 대사도 통과했다.

미구현 상태에서 신규13개 실패 확인 후13개 통과. 추가 통합 테스트의 임시 경로
생성을 보완한 뒤 신규26개 모두 통과(15.17초). Ruff·242파일 포맷·mypy76소스·공백
검사 통과. 전체 pytest884개 통과·22개 생략(402.49초), 커버리지88.23%다.
생략은 일회용 MariaDB 미설정 통합 테스트이며 운영 DB 검증으로 간주하지 않는다.
연구 변경은 백테스트 실행기와 신규 실험 모듈·테스트·이 문서에 한정했다.
