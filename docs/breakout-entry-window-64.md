# 실험64 — 실험57의 진입 고점 창 단축

## 실행 전 계약

실험63에서 사전 명시한 후보 `liquidation-buffer-entry84` 하나를 평가한다.
실험57의 이전168봉 고점 진입만 이전84봉 고점으로 바꾸고,
현재 확정 종가가 그 고점×1.001을 **초과**하면 매수 신호를 낸다.
현재 봉은 고점 창에서 제외한다. 84는 기존 창의 절반이며 여러 기간을 탐색하지 않는다.

청산48봉·채널 리셋48봉·TR24·추세 맥락24봉·50 진입 예산·57 청산 버퍼,
손절 확인2봉·실제 체결 후 리셋·기존 위험 우선순위는 유지한다.
연구용 옵션만 추가하며 운영 전략 함수나 기본168 동작은 바꾸지 않는다.
다른 맥락 선택기나 임의 진입 창을 결합하지 못하도록 검증한다.

같은22개 연속 계좌, 원금100만원씩, 준비봉200개, 기본/슬리피지2배/비용2배/
지연1시간을 사용한다. 결측 보간 없음, 실거래·Config Server·DB·배포·버전 변경 없음.
이 자료는 이미 관측한 탐색 자료이며 새 미관측 검증이 아니다.

대조군은 원 돌파·현금·실험50·실험57이다. 실험62와 전체 JSON352개가 일치해야 하며
후보 포함440개 결과의 체결 손익과 최종 자산을 대조한다.
통과 기준은 네 조건 모두 원 돌파 대비 계좌별 대응 수익률 차이 중앙값>0,
수익 계좌 과반, 최대 낙폭≤10%, 중단0; 기본 자연 청산10건 이상이다.
실험57 대비 대응 차이와 손익도 별도 보고한다. 통과해도 자동 승격하지 않는다.

## 재현

```sh
.venv/bin/python -m evergreen.research.experiments.breakout_entry_window \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/strategy-family-62 \
  --output outputs/breakout-entry-window-64
```

초기9개 테스트가 미구현 옵션을 검출하는 RED를 확인했다.
집중 테스트는 현재 봉 제외, 창의 양 끝, 엄격한 초과, 원래 신호 시각·다음 시가 및
지연 체결, 장세 허가, 옵션 조합 제한, 기본값 재현, 대조군 변조 거부를 포함한다.
변동 폭0인 가상 입력은 기존 진입 예산이 차단하므로 경계 fixture에는 작은 과거 변동을 넣었다.
사용자 지시에 따라 독립 리뷰는 생략한다.

### 손익 차이가 큰 계좌

모든 시각은 UTC다. 독립 계좌 간 합산 외에 개별 거래를 독립 효과로 합치지 않는다.

- `block-000`: 실험57 대비−130,090원. 기존은02-01 손실 후02-04 진입에서
  +68,159원을 얻었다. 84시간 후보는01-12·01-26에 먼저 진입해−30,414·−41,253원
  손실이 쌓였고,02-02 위험 중단으로 뒤의02-04 거래를 하지 못했다.
- `block-005`: +128,629원 개선.02-15 대신02-14,03-13 15시 대신00시에 진입해
  같은 청산 시점까지 더 긴 상승 구간에 참여했다. 다만 후속 수량·고점도 달라지므로
  이 계좌의 차이를 진입 시각 하나의 순수 인과 효과로 해석하지 않는다.
- `block-019`: −128,488원 악화. 기존4번 대신7번 거래했고,01-12·02-14·03-25·

## 후속 실험65 사전 계획 — 조기 돌파의 장기 평균가격 조건

검증: 집중36개 통과(4.66초), 전체789개 통과·격리 MariaDB 미설정22개 건너뜀
(240.46초). Ruff·포맷·mypy72개 소스·diff 공백 검사 통과.
연구와 회귀 테스트 프로세스는 모두 정상 종료했다. 기존 미커밋 연구는 보존했으며
커밋·푸시·운영 시스템 변경은 하지 않았다.

64의 후보는 승격하지 않는다. 조기 진입의 일부 이익과 실패한 반등 증가를 함께
관측했으므로, 다음 후보 하나 `liquidation-buffer-entry84-trend168`을 고정한다.

- 84시간 고점×1.001 초과에 더해, 같은 신호 종가가 **현재 봉을 제외한 이전168봉
  종가 평균보다 엄격히 클 때만** 신규 진입한다. 보유 청산에는 이 조건을 사용하지 않는다.
- 168은 기존 장기 관측 창을 재사용한다. 별도 기울기·여유율·모델 점수 조건을
  추가하지 않고 여러 기간이나 임계값 중 최선을 고르지 않는다.
- 가설: 장기 평균가격 아래의 반등 진입을 줄여64의 손실을 완화한다.
  반례 가능성: 추세 회복 초기를 놓치거나 유효 거래가 줄어든다.
- 원래57 청산·진입 예산·리셋·위험 우선순위,22개 계좌·준비봉200개·네 비용/지연
  조건·원 돌파 기준 공통 통과 조건은 그대로다. 실험57·64 대비 손익도 별도 보고한다.
- 실험64의 기존5개 모델×22계좌×4조건, 총440개 전체 JSON을 대조한다.
  후보 포함528개 손익 검증, 현재 봉 제외·평균 경계 동일/초과·보유 청산 불변을 테스트한다.
- 이미 본 자료의 탐색이며 통과해도 새 미관측/전진 검증이 필요하다.
