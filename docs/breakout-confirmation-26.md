# 실험 26 — 연속 두 시간 돌파 확인

## 사전 계획

실험 25의 원래 돌파 기본 비용 거래 72건을 사후 분류했다. 최초 신호 다음 봉에서도
원래 돌파 조건이 성립한 거래는 19건 중 13건 수익, 나머지는 53건 중 20건 수익이었다.
각 집단의 기존 체결 손익 합계는 +654,641원/+534,878원이었다.
확인을 기다리면 승률이 낮은 집단을 거를 가능성이 있지만 수익 거래 20건도 놓칠 수 있다.
이는 기존 거래의 사후 분류이지 새 전략 손익이 아니며, 기다린 뒤 체결 가격·계좌 경로를 다시 계산한다.

- 후보 하나: 현재 확정 봉과 직전 확정 봉이 각각 자신의 이전 168시간 고점 ×1.001을
  초과해 마감한 경우에만 진입한다. 두 봉에 같은 고점을 적용하는 규칙이 아니다.
- 이전 봉 조건은 과거 봉만으로 계산하고 현재 봉 조건은 기존 돌파 엔진이 평가한다.
  신호 다음 시가 체결, 스트레스에서는 추가 1시간 지연. 확인된 종가로 소급 체결하지 않는다.
- 기존 48시간 저점 청산·10% 영구 위험 중단·전액 매매를 유지한다. 빠른 청산/재진입 대기와
  혼합하지 않는다. 2시간보다 긴 확인이나 진입 버퍼 탐색을 하지 않는다.
- 대조는 원래 돌파·현금, 동일 22개 연속 계좌·36,384시간·200시간 워밍업·4비용/지연.
  원래 돌파의 전체 결과를 실험 25와 재현 대사하고, 원자료 SHA 일치도 요구한다.
- 모든 비용 조건에서 원래 돌파 대비 대응 수익 차이 중앙값 >0, 양수 구간 과반,
  최악 낙폭 ≤10%, 위험 중단 없음, 기본 청산 ≥10회를 모두 요구한다.
- 기존과 동일하게 구간별 별도 100만 원이며 분기 경계에서는 계좌를 유지한다.
  결측을 연결하지 않는다. 이미 본 자료의 탐색이며 새 홀드아웃·실거래 수익 입증이 아니다.
- 모델 학습·운영 전략·Config Server·DB·배포·버전·커밋·푸시 변경 없음.

## 결과

후보는 사전 기준에 미달했다. 기본 비용 합산 순손익이 소폭 늘었지만 구간별 개선은
일관되지 않고, 최대 낙폭 및 위험 중단 기준도 통과하지 못했다. 채택하지 않는다.

다음 수익률은 구간마다 독립 원금 100만 원을 배정한 순수익률의 중앙값이다.
한 계좌의 누적·연환산 수익률이 아니다. 원래 돌파는 같은 평가 시점·위험·비용 조건이다.

| 조건 | 원래 돌파 중앙값 | 확인 후보 중앙값 | 후보−기존 대응 차이 중앙값 | 후보 최악 낙폭 |
|---|---:|---:|---:|---:|
| 기본 | +2.00% | +0.46% | −1.455%p | 10.85% |
| 슬리피지 2배 | +1.11% | +0.26% | −0.976%p | 11.12% |
| 수수료·슬리피지 2배 | +0.19% | +0.16% | −0.828%p | 11.25% |
| 체결 1시간 추가 지연 | +1.69% | +0.30% | −1.701%p | 10.62% |

후보 기본 조건: 거래 구간 19/22개, 양수 구간 11/22개, 자연 청산 46회,
위험 중단 3구간. 네 조건의 중단 구간은 순서대로 3/3/3/2개다.

총 원금 2,200만 원인 22개 모의 계좌의 기본 비용 합산 순손익은 기존 +1,189,519원,
후보 +1,204,498원으로 후보가 14,979원 높다. 수수료는 75,691→48,907원,
슬리피지 비용은 151,383→97,814원으로 줄었다. 합산 이익의 작은 개선만으로
대응 비교·낙폭·양수 구간 기준의 실패를 덮어쓰지 않는다.

기본 조건에서 개선은 7구간, 악화는 15구간이다. `block-011`의 +382,609원 개선이
다른 구간의 악화를 상쇄했다. 반면 추가 체결 지연 조건에서는 합산 손익도 기존 대비
404,684원 낮았다. 특정 한 구간의 개선이나 기본 체결 타이밍에 의존한 결과로는
안정적인 개선 후보라고 판단할 수 없다.

## 재현과 검증

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_confirmation \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/breakout-cooldown-25 \
  --output outputs/breakout-confirmation-26
```

- 종료 코드 0, 원래 돌파의 88개 결과(22구간×4조건)가 실험 25와 체결·자산 곡선까지 일치했다.
- 입력 SHA 재확인 통과. 총 352개 백테스트, 모델 추가 학습 없음.
- `seed-17`은 저장 슬롯이며 학습 시드가 아니다. `prior`는 항상 진입을 허용하는 원래 돌파의
  중복 대조다. `confirm-1h` 결과는 1시간 더 관찰한 후의 신호이며 스트레스 지연은 별도로 추가된다.
- 현재/직전 봉 분리, 미래 봉 변경 불변, 확인 후 다음 시가·추가 지연 체결,
  현재 봉 돌파 실패 시 진입 금지, 이전 결과 재현 실패 시 성공 기록 금지를 테스트했다.
- 전체 테스트 355개 통과, 테스트용 MariaDB 미설정 22개 제외, 커버리지 89.13%.
  Ruff 검사·포맷, mypy 64개 소스, `git diff --check` 통과.
- Spark 읽기 전용 독립 CLI 리뷰 APPROVE, 조치 필요 발견 없음.
  구현 검증과 별개로 수익성 사전 기준은 실패했으며 운영 승격하지 않는다.
- 실거래·Config Server·DB·배포·버전·커밋·푸시 변경 없음.
