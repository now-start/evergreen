# 실험62 — 기존 RSI·밴드 전략의 장기 계좌 비교

## 사전 계약

실험61의 후속 계획대로 진입 전략 종류를 넓힌다. 기존 `rsi-rebound-v1`과
`band-reversion-v1` 함수를 변경 없이 실행한다. RSI14·30/55·SMA168,
이전24봉 평균·모집단 표준편차2배라는 기존 조건을 조정하지 않는다.
후보에 breakout 전용 진입 예산·청산 버퍼·추세 선택기를 붙이지 않는다.

- 이미 관측한 2022–2026년의 22개 연속 계좌, 36,384시간, 준비봉200개.
- 계좌마다 최초100만원, BTC/KRW 현물 전액 매수·매도, 다음 시가 체결.
- 기본 수수료·슬리피지 및 기존10% 영구 중단 규칙을 그대로 유지한다.
- 기본, 슬리피지2배, 비용2배, 체결1시간 지연을 별도로 평가한다.
- 대조군: breakout-v1, 현금, 실험50 entry-stop-budget, 실험57 liquidation-buffer.
- 실험60의 대조군 전체 JSON 352개와 정확히 일치해야 한다.
- 총528개 결과 모두 체결별 손익과 최종 자산을 대조한다.

후보 통과 조건은 네 조건 모두에서 원전략 대비 **계좌별 대응 수익률 차이의
중앙값>0**, 수익 계좌 과반, 최대 낙폭≤10%, 중단 계좌0이다.
기본 조건에서는 경계 정산을 제외한 청산이10건 이상이어야 한다.
10% 중단 문턱은 갭·비용·지연 상황에서 손실 상한을 보장하지 않는다.
새 미관측 검증이나 실거래 승격이 아닌 탐색 연구이며 학습 모델은0개다.

실거래·설정 서버·DB·배포·버전은 변경하지 않는다. 사용자 지시에 따라 독립 리뷰는 생략한다.

### 기본 비용의 손익 분해

원자료나 수량을 바꾸지 않고 각 완결 거래를 다음과 같이 대조했다.
`순손익 + 양방향 수수료 + 양방향 슬리피지 = (매도 기준가격−매수 기준가격)×수량`.
각 거래의 차이가0.000001원 미만임을 확인했다.

| 항목 | RSI | 밴드 |
|---|---:|---:|
| 경계 정산 포함 거래 | 221 | 321 |
| 비용 차감 후 이익 거래 | 84 | 160 |
| 같은 체결의 기준가격 손익이 양수인 거래 | 113 | 207 |
| 보유 시간 중앙값 | 7시간 | 15시간 |
| 신호 / 위험 / 경계 정산 청산 | 218 / 2 / 1 | 304 / 16 / 1 |
| 수수료 합 | 216,616원 | 320,964원 |
| 슬리피지 합 | 433,231원 | 641,927원 |
| 같은 시각·수량의 기준가격 손익 합 | -191,556원 | -496,890원 |

비용이 손실을 키웠지만 **같은 거래들의 가격 손익도 이미 음수**다.
이는 비용0으로 계좌를 다시 운용한 반사실 백테스트가 아니다. 비용을 실제로 바꾸면
수량·고점·중단 시점·후속 거래도 바뀌므로 비용을 더한 값으로 그 성과를 주장하지 않는다.

### 최악 낙폭 계좌의 첫 문턱 초과

실험56의 읽기 전용 mark 관찰기로 각 후보 기본 조건의 최대 낙폭 계좌를 재실행했다.
원래 전체 JSON과 일치하고 관찰 곡선도 일치했다. 시각은 UTC다.

- RSI `block-015`: 2025-03-07 02:00 매수 직후 낙폭9.9351%에서,
  03:00 종가 평가11.3485%로 초과했다. 기준가격132,417,000→130,339,000원.
  최초 초과는 비용 발생 시각이 아닌 보유 가격 하락이며 이후 최대11.4814%가 됐다.
- 밴드 `block-014`: 2024-12-03 13:00 시가 평가 낙폭0.3439%에서,
  14:00 종가 평가12.5573%로 초과했다. 기준가격132,715,000→116,450,000원.
  역시 보유 가격 하락이며 이후 최대13.4757%가 됐다.

밴드의 높은 거래 승률만으로 급락 손실을 상쇄하지 못하며,
시간봉 평가·다음 시가 청산 체계의10% 문턱은 엄격한 손실 상한이 아니다.

## 후속 실험63 사전 계획 — 비용과 계좌 경로 효과 분리

검증: 전체 회귀769개 통과·격리 MariaDB 미설정22개 건너뜀(271.96초).
전체 실행 이후 실제 지연 매수·매도2건과 계좌 조건 불일치 검증을 추가했고,
최종 집중9개가 통과했다(14.46초). Ruff·포맷·mypy70개 소스·diff 공백 검사가 통과했다.
소스·테스트·문서만 추가했으며 기존 전략 함수와 운영 코드는 바꾸지 않았다.

RSI·밴드를 승격하거나 임계값을 조정하지 않는다. 위의 고정 체결 비용 분해와
실제 비용 변경 시 계좌 경로 효과가 어떻게 다른지 진단한다.

- 대상: RSI, 밴드, 기존 breakout-v1, 실험57 liquidation-buffer 네 전략.
- 같은22개 계좌·준비봉200·원금100만원·기본 체결 시각·기존 위험 규칙.
- 비용 조건을 기본, 수수료만0, 슬리피지만0, 모두0으로 사전 고정한다.
- 기본88개 전체 JSON을 실험62와 비교하며 나머지264개도 체결 손익을 대조한다.
- 비용별 실제 재실행 수익·거래 수·중단·낙폭을 보고하고 기본 거래에 비용만 더한
  분해값과 구별한다. 비용 절감으로 성과가 단조 개선된다고 가정하지 않는다.
- 비용0은 구현 가능한 거래 조건이나 수익 후보가 아닌 진단 대조다. 별도 승격 게이트는
  없으며 실제 비용에서 실패한62의 판정은 유지한다. 딥러닝 학습도 수행하지 않는다.

실험08에서 이미 SMA48/168의 장기 비교가 있었으므로 동일 계열을 단순 재실행해
새 연구 성과로 포장하지 않는다. 이번 진단 후 비용 민감도와 가격 손익을 근거로
다음 전략 변경 여부를 판단한다.
