# 실험 40 — 진입가 기준 고정 손절

## 사전 고정 계획

[실험39 후속 계획](breakout-rejection-latch-39.md)의 한 후보 `entry-stop-tr24`를 검증한다.
추격 차단은 처음부터 통과한 큰 손실을 바꾸지 못했고, 이전 고점 추적 청산은 수익 추세를
분절했다. 이번에는 원래 진입을 유지하고 초기 진입가 아래에 고정한 손절만 추가한다.

- 실제 매수 시가−3×진입 신호 이전24봉 평균 TR을 체결 시 고정한다. TR은 기존 공통
  함수의 고저/이전종가 차이 최댓값 평균이며 신호 봉 제외·첫 TR용 이전종가 포함.
- 실제 매수 후 확정 종가가 기준 미만이면 다음 시가 매도한다. 동률이면 추가 매도 없음.
  진입 TR이0이면 추가 손절 비활성. 기준이0 이하라면 양수 종가로 하회할 수 없다.
- 지연 체결에서도 원래 신호의 TR과 실제 지연 시가를 사용한다. 장중 저가로 손절
  체결을 추정하지 않고, 이후 TR·고점 변화로 기준을 변경하지 않는다. 새 실제 매수마다
  재설정하고 매도 후 제거한다. 체결 대기 주문을 재판단하지 않는다.
- 원래168시간 최고가×1.001 진입·48시간 저점 청산·10% 영구 위험 중단 유지.
  진입 필터·거절 기록·추적 청산·재진입 대기와 결합하지 않는다.
- 24시간·3배는 실험34에서 사용한 단위의 재사용이며 최적값이 아니다. 결과에 맞게 조정 없음.
- 동일 원자료SHA·200시간 워밍업·22개 독립 연속 계좌·각100만 원·36,384/40,896시간
  (88.97%), 구간 내부 분기 경계 상태 유지, 결측 보간 없음.
- 전액 다음 시가 체결, 양쪽 수수료0.05%·슬리피지0.1%, 최소5천 원·수량1e-8.
  슬리피지2배·비용2배·추가1시간지연 비교. 비용·갭 때문에 손실 상한은 보장되지 않는다.
- 기존·현금·prior·실험39·후보 총440회, 기존/39 전체176개 JSON 재현과 입력/소스 SHA 검증.
- 모든4조건에서 기존 대비 대응 수익률 차이 중앙값>0, 수익 구간 과반, 최악 낙폭≤10%,
  위험 중단 없음, 기본 자연 청산10회 이상 요구.
- 손절 뒤 반등 기회 상실·재진입 비용 증가·수익 반납 낙폭은 남을 수 있다. 이미 본 자료의
  탐색이며 신규 홀드아웃/딥러닝 학습/실거래 성과 아님. 독립 계좌 합산 손익은 단일 누적
  또는 연환산 수익이 아니다. 실거래·Config Server·DB·배포·버전·커밋·푸시 변경 없음.

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_confirmation \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/breakout-rejection-latch-39 \
  --output outputs/breakout-entry-stop-40 \
  --entry-stop
```

현재까지 결과를 보존하는 체크포인트이며 새 실험은 이 문서에서 추가 실행하지 않는다.
이미 본 자료의 탐색 결과이고, 실거래 전략·설정·DB·배포·버전은 변경하지 않았다.
사용자의 후속 요청에 따라 실험38~40 코드·테스트·문서를 함께 커밋·푸시 대상으로 한다.

## 검증

- 전체493개 테스트 통과·22개 제외(테스트용 MariaDB 미설정), 커버리지89.24%.
- 관련51개 테스트 통과. 신호 봉 제외·동률·지연 시가·고정 기준·재진입 초기화·위험
  우선순위·최소 주문 미달·혼합 옵션 거부·대조 손상 시 실패를 검증했다.
- Ruff 검사·포맷170개·mypy65소스·diff 공백 검사 통과.
- 원자료와 실행 산출물은 기존 ignore 정책대로 커밋하지 않는다. 재현 명령과 결과 요약을
  문서로 보존하며, 위 SHA 검증은 실행 완료 시 로컬 산출물에 대해 수행했다.
- 커밋 전 독립 리뷰: Spark 사용량 제한으로 승인된 대체 모델 `gpt-5.5`의 읽기 전용

  차단 이슈 없음. 코드 리뷰 승인이며 수익성 또는 실거래 채택 승인이 아니다.
