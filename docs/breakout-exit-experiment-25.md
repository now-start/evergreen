# 실험 25 — 빠른 청산 후 24시간 재진입 대기

## 실행 전 고정 계획

실험 24에서 24시간 청산 후 하루 이내 재진입한 가상 거래 7건 중 6건이 비수익이었다.
표본이 작고 이미 본 자료이므로, 이것만으로 대기 규칙의 수익성을 주장하지 않는다.
하루 대기가 재진입 비용을 줄이는지, 상승 재개를 놓쳐 오히려 손실인지 분리 검증한다.

- 후보 하나: 168시간 고점 돌파 진입, 24시간 저점 청산, 실제 매도 체결 후 24시간 재진입 대기.
- 실제 체결된 매도만 대기 시작점을 갱신한다. 주문 신호·거절 주문은 대기를 시작하지 않는다.
  신호 시점이 매도 체결 시점+24시간 미만이면 신규 진입을 무시한다. 만료 시점부터는
  그 시점의 돌파 조건을 다시 평가해 다음 시가에 체결한다. 대기 중 신호를 예약하지 않는다.
- 기존 보유 청산·위험 중단에는 대기를 적용하지 않는다. 최초 진입에는 대기가 없다.
  같은 연속 계좌에서는 분기 변경에도 대기를 유지하고, 결측 후 별도 계좌에서만 초기화한다.
- 대조는 원래 48시간 청산 돌파, 실험 24의 대기 없는 24시간 청산, 현금이다.
  24시간 청산 대조와 원래 돌파의 22구간×4비용 전체 결과가 실험 24와 일치해야 한다.
- 같은 원자료 SHA·200시간 워밍업·22개 계좌·4비용/지연·전액 매매·원금·10% 위험 중단 유지.
  24시간 외 대기 시간·다른 청산 채널·진입 조건·임계값은 탐색하지 않는다.
- 원래 돌파 및 대기 없는 24시간 청산 각각 대비 대응 구간 수익 차이 중앙값 >0,
  양수 구간 과반, 최악 낙폭 ≤10%, 위험 중단 없음, 기본 비용 청산 ≥10회를 모든 조건에서 요구한다.
- 모델 학습·레이블·실거래·Config Server·DB·배포·버전·커밋·푸시 변경 없음.
  이 실험은 이미 반복 탐색한 역사 자료를 사용하며 미관측 검증이 아니다.

## 재현

```bash
.venv/bin/python -m evergreen.research.experiments.breakout_exit \
  --raw data/regime-08-2020-2026-public \
  --reference outputs/breakout-exit-24 \
  --output outputs/breakout-cooldown-25 --cooldown-hours 24
```

출력은 새 디렉터리여야 한다. `seed-17`은 연구 결과 저장 슬롯이고 학습 시드가 아니다.
`prior`는 원래 돌파와 같은 항상 진입 허용 대조다. Result 스키마는 유지하고 후보 파일명
`exit24-cooldown24` 및 실험 프로토콜에 재진입 대기 조건을 기록한다.
