# 실험 12: 균형 학습 돌파 필터의 시드 안정성

## 결과 확인 전 고정한 계획

- 후보는 실험 11의 `balanced + breakout-filter` 한 개다. 기존 돌파와 현금을 대조군으로 둔다.
- 시드는 17·29·43으로 고정한다. 가장 좋은 시드를 선택하거나 시드 결과를 독립 시장 표본으로 합산하지 않는다.
- 세 시드 모두 새로 학습한다. 원본·분할·24시간 레이블·특징·가중 학습·비가중 검증 CE·조기 종료,
  점수 0.55·3시간 확인·6시간 유지·비용·위험 중단·결측 제외 정책은 실험 11과 같다.
- 과거 평가는 각 시드마다 동일 22개 연속 블록의 독립 원금 100만 원이다.
  같은 블록의 필터와 돌파 순수익 차이, 거래한 블록 수, 거래 수, 비용, 낙폭을 비교한다.
- 탐색 안정성 조건: 모든 시드/비용 조건에서 양수 구간이 절반 초과, 돌파 대비 수익 차이 중앙값 양수,
  낙폭 10% 이하·위험 중단 없음, 기본 비용 청산 10회 이상. 이는 실거래 승격 조건이 아니다.
- 보조 평가: UTC 2026-09-01 00:00~2026-09-09 00:00, 총 192시간.
  별도 169시간 워밍업과 확정된 공개 시간봉만 사용한다. 결측이면 보조 평가는 실패로 남기고 보간하지 않는다.
- 보조 평가에는 각 시드의 2026-07-01 분기 모델을 그대로 사용한다. 7~8월 및 9월 가격을 학습에 추가하지 않는다.
  모델 해시·학습/검증 종료 시각을 검증하고 안전한 가중치 로딩만 사용한다.
- 보조 평가 시작에는 독립 원금으로 재시작한다. 과거 블록 결과와 이어 붙인 운영 성과가 아니다.
  이미 발생한 최근 자료의 사후 평가이며 실시간 paper 운영도 아니다. 8일은 신규 검증으로 충분하지 않다.
- 실거래·계좌·Config Server·DB·배포 변경 없음. 좋은 과거 결과도 자동 승격하지 않는다.

## 실행

```bash
uv run python -m evergreen.research fetch \
  --start 2026-08-24T23:00:00Z --end 2026-09-09T00:00:00Z \
  --output data/regime-12-september
uv run python -m evergreen.research.experiments.regime_stability \
  --source data/regime-08-2020-2026-public \
  --recent data/regime-12-september \
  --output outputs/regime-experiment-12
```

새 출력 경로만 사용한다. 각 시드의 모델/예측/주문/원금 곡선과 한글 결과 보고서를 보존한다.

재현성 설정은 [PyTorch 공식 안내](https://docs.pytorch.org/docs/stable/notes/randomness.html)에 따라
시드와 결정론적 알고리즘을 함께 고정한다. 서로 다른 환경·라이브러리 버전에서의 동일 결과까지 보장하는 것은 아니다.

## 실행 결과 — 2026-09-09

`outputs/regime-experiment-12/` 완료. 각 시드 19개 분기 모델, 22개 연속 블록, 37,066시간을 평가했다.
시드 17의 과거 연속 블록 결과는 실험 11의 균형 학습 결과와 정확히 재현됐다.
아래는 기본 비용이며 수익은 독립 블록 중앙값, 차이는 같은 블록의 필터 수익에서 돌파 수익을 뺀 값의 중앙값이다.

| 시드 | 수익 중앙값 | 거래한 구간/22 | 양수 구간/22 | 청산 | 최악 낙폭 | 돌파 대비 차이 |
|---|---:|---:|---:|---:|---:|---:|
| 17 | 0.00% | 3 | 3 | 7 | 8.43% | -1.04%p |
| 29 | 0.00% | 5 | 4 | 8 | 5.97% | -1.03%p |
| 43 | 0.00% | 9 | 4 | 17 | 6.73% | -2.21%p |

- 시드에 따라 거래 빈도와 손실 구간이 달라졌다. 기존 돌파의 기본 비용 수익 중앙값은 같은 구간에서 +2.00%다.
- 전체 비용 두 배에서 시드 17·29의 돌파 대비 차이 중앙값은 약 +0.01%p이나, 시드 43은 -0.70%p다.
  일부 비용 조건만 선택해서 안정적인 개선으로 해석하지 않는다.
- 최근 8일은 모든 시드/비용에서 필터와 기존 돌파 모두 거래·노출·수수료 0이다.
  새로운 기간에서 실행 경로는 검증했지만 수익성 판단에 필요한 거래 표본은 얻지 못했다.
- 시드 안정성 사전 조건 미충족. **기존 전략 교체 및 실거래 승격 없음.**

기존 임계값을 낮춰 거래 수만 늘리는 대신, 다음 연구에서는 장기 추세 입력이나 진입 판단 목표의 유효성을
대조군과 비교해야 한다. 이 문서는 해당 다음 실험의 성과를 주장하지 않는다.
