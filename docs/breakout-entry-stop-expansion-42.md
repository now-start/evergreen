# 실험 42 — 변동 폭 확대 진입에만 고정 손절 활성

## 사전 고정 계획

[실험41 오류 분석과 후속 계획](breakout-entry-stop-floor-41.md)에 고정한 후보 하나
`entry-stop-expansion`을 검증한다. 손절 폭을 넓히는 것만으로 짧은 조정/하락을 구분하지
못했으므로 이번에는 거리 조정 대신 진입 시 활성 조건 하나를 비교한다.

- 원래 돌파 매수 조건을 유지하고 변동 폭 때문에 매수 신호를 차단하지 않는다.
  청산 변화에 따른 이후 매수 시점/횟수는 달라질 수 있다. 실제 매수 때 진입 신호 이전 TR24>TR168인
  경우에만 실제 매수 시가−3×TR24 추가 고정 손절을 활성화한다. TR24≤TR168이면
  해당 포지션에서는 비활성. 동률/둘 다0은 비활성이며 나눗셈은 사용하지 않는다.
- 두 평균 TR은 공통 함수로 신호 봉 제외·첫 TR의 이전종가 포함하여 계산한다.
  최소170봉을 요구하고 실제 비교는200봉 워밍업을 제공한다.
- 지연 체결도 신호 당시 조건과 실제 지연 시가를 사용한다. 실제 체결이 없는 주문은
  기준을 만들지 않는다. 새 실제 매수마다 재판단, 매도 후 초기화한다.
- 활성 포지션의 확정 종가가 고정 손절선 미만이면 다음 시가에 매도한다. 동률/장중 저가만으로
  청산하지 않는다. 보유 중 TR·고점 변화로 기준이나 활성 상태를 바꾸지 않는다.
- 비활성은 추가 손절만 끄는 것이다. 원래168시간 최고가×1.001 진입·48시간 저점 청산·
  10% 영구 위험 중단·체결 대기 주문과 위험 우선순위를 유지한다.
- 실험37의 진입 필터와 다르며 저변동 폭 진입을 차단하지 않는다. 실험41 손절 거리 하한·
  고점 추적·쿨다운·거절 기록·다른 조건과 결합하지 않는다. 기간24/168·비율1·배수3은
  기존 값 재사용이고 최적값 주장이 아니다. 결과에 맞춰 변경하거나 다중 후보를 탐색하지 않는다.
- 동일 공개 BTC/KRW 원자료·SHA·22개 독립 연속 계좌·각100만 원,
  36,384/40,896시간(88.97%), 구간 내부 분기 경계 상태 유지·결측 보간 없음.
- 전액 다음 시가, 양쪽 수수료0.05%·슬리피지0.1%, 최소5천 원·수량1e-8.
  슬리피지2배·비용2배·추가1시간 지연까지4조건. 비용·갭 때문에 손실 상한은 보장되지 않는다.
- 기존·현금·prior·실험41·후보 총440회. 기존/41 전체176개 JSON 재현과

## 다음 사전 명시 실험 43 — 고정 손절의 연속 두 종가 확인

후보 하나 `entry-stop-confirm2`를 검증한다. 실험40의 원래 진입·고정3×TR24 손절로
돌아가되 추가 손절만 두 개의 연속 확정 종가가 하회해야 예약한다.

- 실제 매수 시가−3×원래 진입 신호 이전24봉 평균 TR을 체결 시 고정한다.
  신호 봉 제외·이전종가 포함·실제 지연 시가 기준·0 TR 비활성은 실험40과 같다.
- 실제 매수 이후 시작한 봉 두 개의 종가가 모두 기준 미만일 때만 다음 시가 추가 매도한다.
  하나라도 동률/상회이면 확인 연속성이 끊긴다. 매수 전 봉을 확인에 포함하지 않는다.
- 원래48시간 채널 청산이나10% 위험 중단은 두 봉을 기다리지 않는다. 예약된 주문을
  이후 복귀 종가로 취소하지 않는다. 추가1시간 지연은 확인 후 체결 대기에 적용한다.
- 새 실제 매수/매도 시 기준 초기화, 미체결 주문에는 기준 없음. 확대 조건·장기 TR 하한·

- 반등 직전 손절을 줄일 수 있으나 급락에서는 더 늦고 나쁜 가격에 매도할 수 있다.
