# 실험 20 결과 — 저복잡도 선형 대조군

## 결론

파라미터를 161개로 줄여도 기존 돌파 대비 안정적인 우위는 확인되지 않았다.
비가중 고정 기준의 시드 29에서만 좋은 결과가 나타났고 다른 시드에서는 재현되지 않았다.
세 조건 모두 기존 사전 기준 미달이며 운영 전략은 변경하지 않았다.

## 기본 비용 결과

편도 수수료 0.05%·슬리피지 0.1%. 22개 연속 블록마다 독립 원금 100만 원.
수익률은 미거래 구간을 포함한 블록별 순수익률 중앙값으로, 하나의 계좌 누적 수익률이 아니다.

| 후보 | 시드 17 | 시드 29 | 시드 43 |
|---|---:|---:|---:|
| 원래 돌파 | +2.00% | +2.00% | +2.00% |
| 선형 / 비가중 / 0.50 | -0.27% | +3.02% | 0.00% |
| 선형 / 비가중 / 학습 손익 기준 | +2.00% | +1.65% | +1.07% |
| 선형 / 손익 가중 / 0.50 | +1.62% | +0.57% | +0.13% |

자연 청산은 조건 순서대로 53/53/49회, 71/71/72회, 68/69/62회였다.
시드·4개 비용/지연 조건 전체 최악 낙폭은 각각 10.68%, 10.95%, 11.02%였다.
10% 위험 중단은 다음 봉 체결·비용을 포함한 실제 손실 상한이 아니다.

대응 구간 비교에서도 시드 29의 고정 기준만 같은 비가중 MLP 대비 +0.84%p,
CNN 대비 +3.19%p 중앙값 차이가 있었다. 반대로 시드 43의 가중 선형은 가중 MLP/CNN보다
각각 -0.82/-0.73%p 낮았다. 좋은 시드만 채택하는 근거로 사용하지 않는다.

## 모의 계좌 손익과 오류

원래 돌파 대비 원화 손익 차이 합계. 각각 100만 원으로 시작한 22개 독립 계좌,
총 배정 원금 2,200만 원의 비교이며 동일 시각의 진입·추가·제거 거래를 대사했다.

| 선형 조건 | 시드 17 | 시드 29 | 시드 43 |
|---|---:|---:|---:|
| 비가중 / 0.50 | -269,951원 | +488,849원 | -350,769원 |
| 비가중 / 학습 손익 기준 | -123,905원 | +60,250원 | -34,348원 |
| 손익 가중 / 0.50 | -50,898원 | -270,789원 | -408,532원 |

동일한 완결 가상 사건 468개(양수 218·0 이하 250)에서 고정 기준 선형 모델의 Brier는
0.2620/0.2570/0.2656으로 학습 승률 상수 0.2557보다 모두 나빴다.
고정 기준에서 놓친 양수 사건은 117/116/143개, 회피한 0 이하 사건은 144/153/161개였다.
손익 기준으로 진입을 늘리면 놓친 양수는 28/21/25개로 줄지만 회피 손실도 14/16/14개로 줄었다.
겹치는 가상 사건은 독립 거래 표본이 아니며 사건별 수익 평균은 실제 계좌 수익률이 아니다.

## 검증

- 세 조건 모두 종료 코드 0, 실패 파일 없음. 모델 57개씩 총 171회 학습.
  비가중 두 조건의 체크포인트 57쌍은 바이트 단위로 같아, 서로 다른 모델 171개라는 뜻은 아니다.
- 총 3,168개 비교 백테스트에 반복 대조군 포함. 독립 통계 실험 수가 아니다.
- 16/17/19와 사건·coverage 파일, 학습/검증 표본 해시가 같았다.
  대응 목적의 원래 돌파·현금·상수 대조군은 모든 시드·블록·비용 결과가 정확히 같았다.
- 37,066시간, 계획 대비 90.63%의 같은 22개 블록을 평가했다. 결측 보간과 블록 간 계좌 연결 없음.
- 기존·선형 모델의 학습/저장/재로딩, 시드 재현성, 3조건 연결, 부족한 분기의 현금 유지,
  후보 누락 거부 및 오류 분석 회귀 테스트를 통과했다. 선형 모델은 운영 전략으로 등록하지 않았다.
- 전체 테스트 323개 통과, 테스트용 MariaDB 미설정 22개 제외, 커버리지 89.78%.
  Ruff 검사·포맷, mypy 통과. 운영 DB·Config Server·매매·배포 변경 없음.
- 비가중 57개 중 1개, 가중 57개 중 5개는 최대 100 epoch에 도달했다. 모든 모델의 수렴을 보장하지 않는다.
- 171개 저장 모델의 재로딩과 161개 파라미터를 확인했다. 기존 기본 신경망의 고정 표본
  체크포인트는 변경 전과 바이트 단위로 같았다.
- 사용자 승인 대체 모델 gpt-5.5의 읽기 전용 독립 CLI 리뷰: APPROVE, 조치가 필요한 발견 없음.
