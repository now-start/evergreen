# 딥러닝 비교 실험 03 — 사전 계획

2026-09-07, 모델 학습 및 2026년 평가 데이터 수집 전에 고정한 계획이다.
작은 MLP와 1D CNN 두 후보만 추가한다. 수익 보장·온라인 파인튜닝·실거래 승격은 없다.

## 데이터 분리

| 역할 | 수집 시작 ~ 종료 제외 | 매매 평가 시작 |
|---|---|---|
| 학습 1 | 2024-01-01 ~ 2024-03-01 | 학습 전용 |
| 학습 2 | 2024-07-01 ~ 2024-09-01 | 학습 전용 |
| 학습 3 | 2024-11-01 ~ 2024-12-15 | 학습 전용 |
| 모델 선택 1 | 2025-01-03 ~ 2025-03-01 | 2025-01-11 |
| 모델 선택 2 | 2025-04-01 ~ 2025-06-01 | 2025-04-09 |
| 모델 선택 3 | 2025-07-01 ~ 2025-09-01 | 2025-07-09 |
| 최종 평가 A | 2026-01-05 ~ 2026-03-01 | 2026-01-13 |
| 최종 평가 B | 2026-04-05 ~ 2026-06-01 | 2026-04-13 |

모든 시각은 UTC 00:00이다. 학습·선택 구간은 이전 실험에서 이미 관찰한 데이터다.
2026년은 이번 프로젝트의 미관측 역사적 성과 평가이지 실제 미래 Paper 결과가 아니다.
불연속 구간 사이를 이어 붙여 시퀀스/레이블을 만들지 않는다. 품질 실패 시 해당 실행을
실패로 보존하며 이번 실험 중 평가 기간을 재선택하지 않는다.

## 특성과 레이블

- 입력: 확정된 최근 32봉 × 5개 특성, float32.
- 특성: 종가 로그 변화, 고가/저가 로그 비율, 종가/시가 로그 비율,
  `log1p(거래량)` 변화, 종가/최근 24봉 평균 - 1.
- 마지막 특성을 위해 최소 24봉, 시퀀스와 합쳐 총 55봉이 필요하다.
- 각 특성은 해당 봉까지의 자료만 사용한다. 학습 시퀀스에서만 특성별 평균·표준편차를
  구하고 선택/평가에서는 고정한다. 표준편차 하한 1e-8, 표준화 후 [-10, 10]으로 제한한다.
- 신호 봉 i의 정답은 `open[i+13] / open[i+1]`의 로그 수익률이
  가정한 왕복 수수료·슬리피지의 로그 손익분기 비용 + 0.002를 초과하면 1, 아니면 0이다.
  필요한 미래 시가가 현재 구간 밖에 있으면 레이블을 생성하지 않는다. 인접 표본의
  레이블은 겹칠 수 있으므로 표본 수를 독립 거래 횟수나 통계적 유의성으로 해석하지 않는다.

## 고정 학습 설정과 매매

- MLP: 160 → 32 → 16 → 1, 은닉 ReLU.
- CNN: 입력 (배치, 5, 32), Conv1d 5→16→16, 커널 3, ReLU,
  시간축 평균 풀링 → Linear 16→1. 패딩은 이미 확정된 32봉 내부에서만 사용한다.
- 이진 logits 손실(BCE), Adam 학습률 0.001, weight decay 0.0001, 20 epoch,
  배치 128, 시드 17, CPU 2스레드, gradient norm 1. 고정 최종 epoch만 사용한다.
  선택/평가 데이터를 역전파·정규화·early stopping·학습률 변경에 사용하지 않는다.
- 확률 >= 0.60이면 전액 매수, 보유 중 확률 <= 0.45이면 전액 매도한다.
  12시간 레이블은 예측 과제이며 실제 보유 기간을 강제로 12시간으로 만들지는 않는다.
- 기존 다음 봉 체결·고점 대비 10% 위험 중단·비용·지연·독립 원금 정책을 그대로 사용한다.
  모든 실험의 원금은 모의 100만 원, 편도 수수료 0.05%, 슬리피지 0.1%, 최소 금액 5천 원이다.

## 선택과 판정

선택 세 구간 × 네 비용/지연 조건 중 최저 순수익률이 큰 모델을 하나 고른다.
동률이면 최대 낙폭이 작은 모델, 그래도 같으면 ID 순이다. 선택 파일과 모델 해시를
저장한 다음 최종 평가 데이터를 읽는다. 최종 평가에서 미선정 모델은 실행하지 않는다.

규칙 비교 대상은 현금, BTC 보유, SMA 20/60, SMA 48/168, 고점 돌파,
가격 밴드 평균회귀, RSI 반등이다. 모델 선택 비교 108개 + 최종 평가 비교 64개 = 172개다.
선택/최종 평가 모든 구간·조건에서 양수 수익률, 위험 중단 없음, 최대 낙폭 10% 이하,
SMA 20/60·SMA 48/168·RSI 각각 초과 수익을 요구한다. 최종 두 구간 기본 조건의
청산 합계는 10회 이상이어야 한다. 조건 미달이면 수익성 미검증이며 모델은 승격하지 않는다.

훈련 손실, 학습 양성 비율, 선택/평가 BCE 및 학습 양성 비율 고정 예측의 BCE,
표본 수, 모델·정규화·데이터·코드 해시와 한글 보고서를 저장한다.
체크포인트에는 가중치와 optimizer 상태를 저장하고, 로딩은 `weights_only=True`로 제한한다.
재현성은 같은 환경에서 검사하며 플랫폼/버전 간 완전한 일치를 보장하지 않는다.
[PyTorch 재현성 안내](https://docs.pytorch.org/docs/stable/notes/randomness.html)

## 실행 기록 — 2026-09-07

실제 PyTorch 2.14.0 CPU 환경에서 각 모델을 3,783개 표본으로 20 epoch 학습했다.
학습 양성 비율은 약 37.80%이며, 미래 레이블이 각 구간을 넘지 않도록 제거했다.

| 모델 | 첫 epoch BCE | 최종 epoch BCE | 선택 구간의 최저 순수익률 |
|---|---:|---:|---:|
| MLP | 0.7107 | 0.4823 | -11.07% |
| 1D CNN | 0.6863 | 0.6350 | -2.24% |

후보 선택 규칙에 따라 CNN을 고정했다. 학습 손실이 더 많이 줄어든 MLP를 임의로
선정하지 않았다. MLP의 세 선택 구간 BCE는 학습 양성 비율로만 예측하는 기준보다 모두 높았다.

0% 구간은 진입하지 않은 결과이지 수익을 낸 결과가 아니다. CNN 평가 A BCE는 0.5974로
고정 학습 비율 예측 0.6074보다 낮았지만, 실제 모의 체결은 손실이었다.
분류 손실 개선이 거래 수익 개선을 뜻하지 않음을 보여준다.

평가 A의 1,320개 봉은 통과했다. B는 1,364개 봉과 **2026-04-12 18·19·20·21시 UTC
누락 4개**로 수집에 실패했다. 계획대로 기간을 바꾸거나 데이터를 합성하지 않았고,
선택 108개 + 평가 A 32개 = **140개 비교**만 완료했다. 목표 172개를 완료했다고 보고하지 않는다.

**판정: 수익성 미검증이며 최종 검증 미완료.** 평가 B가 없을 뿐 아니라 이미 선택 1·평가 A에서
손실이 나 연구 수익성 조건도 충족하지 못했다. 모델 자동 승격·실제 주문은 실행하지 않았다.
두 모델의 학습 완료와 거래 전략의 수익성 검증 완료를 구분한다.

최종 모델·원장·한글 보고서는 `outputs/deep-learning-experiment-03-final/`에 보존한다.
첫 실행 `outputs/deep-learning-experiment-03/`과 `-verified`도 보존한다. 후속 실행은
같은 설정의 재현 확인이며 140개 결과와 예측이 일치했다. 최종 실행은 현재 소스 해시도 일치한다.
검증 A는 이제 관찰한 구간이므로 다음 모델 수정의 미관측 최종 검증으로 다시 사용할 수 없다.

20 epoch는 첫 비교를 위한 고정 학습 예산이지 충분한 수렴을 확인한 값이 아니다.
실험 03 당시 구현에는 epoch별 검증 손실과 early stopping이 없었다. 후속 실험에서는 시간순으로
별도 분리한 학습 검증 구간에서 종료 시점과 최적 가중치를 고르고, 최종 평가 구간은
epoch 선택에 사용하지 않아야 한다. epoch를 늘리는 것만으로 수익성 개선을 보장하지 않는다.
